## 打开与重启

[打开工作台](http://127.0.0.1:5178/)。刷新即可使用新版。

运行环境：Node.js 24 或以上（本机已具备），现有依赖已安装。停止服务后，在应用目录运行：

```sh
cd '/Users/nat/Documents/ChatGPT/个人/work/personal-ai-workbench'
npm run build
npm start
```

看到“数码世界 http://127.0.0.1:5178”即已启动。终端保持打开；Ctrl+C 正常停止。只监听本机，不是公网网站。尚未打包为独立 macOS 应用或配置开机启动。不要用旧版单独 Vite 预览代替本地服务。

开发前端时，在本地服务已运行的前提下另开终端执行 `npm run dev`，打开 `http://127.0.0.1:5179/`。页面热更新，`/api` 与 `/packages` 转给 5178 服务；**默认连的是真实主库**。只想用隔离数据时，先 `WORKBENCH_DATA_DIR=$(mktemp -d) PORT=5189 npm start`，再 `WORKBENCH_API_PORT=5189 npm run dev`（仍不隔离本机扫描）。

## 使用

- **项目空间**：第一次打开自动扫描已确认的 `Documents/ChatGPT`、`Documents/AI 项目`，读取本机 GitHub CLI 已登录账户的仓库元数据，自动入库并按 GitHub remote 关联。可搜索、筛选、调整目录、重新扫描、复制位置、在 Finder 显示和打开 GitHub。旧手工记录另行保留。
- **目录重关联**：项目目录移动后先扫描，再打开原项目 →「关联已发现目录」→ 选择新发现的项目，可选择替换一个已证实缺失的旧目录 →「预览关联」→ 核对前后目录并勾选确认。只改工作台关联，不搬移或删除文件；原项目 ID 保留。Current 原选择保留但须重新选目录、预览并保存，才能生成交接包。目录被更换时使用「重新确认目录」，新旧远端在确认前可见。
- **Agent 中心**：第一次打开自动检测 11 种受支持入口，区分程序存在、仅配置痕迹、未检测和检测受阻，可查看与复制位置。发现程序不代表运行、登录或模型连接成功。「上下文接力」支持手动编写与「从项目来源生成」，不读取聊天。
- **Agent 版本与管理目标**：打开 Codex 或 Hermes →「检查版本与目标」，展开程序入口可看版本来源。点「添加目标」，明确选择程序与 Home / Profile、填写名称 →「保存目标」。完整位置显示在选择框下；重开仍保留，可编辑或二次确认解除。保存只记录工作台关联，不切换配置、安装或运行 Agent。遇到过期、来源变化或保存失败，草稿保留，先重新检查再确认。
- **Agent 配置管理**：在已保存的 Codex CLI / Hermes CLI 目标中展开「配置管理」→「读取配置」。选择一个终端显示选项→「预览修改」→核对完整路径和前后值→勾选确认→「确认应用」。结果显示文件回读及当前值，不宣称运行中的 Agent 已采用。需要撤回时，在「变更记录」中点「预览恢复」，核对后再次确认。Codex App 入口不冒充 CLI。
- **Agent 目录与资产**：打开 Codex 或 Hermes 卡片 →「目录与资产」。查看默认 Home、当前服务环境指定的额外 Home、Hermes Profile 目录，以及独立的 Codex 用户共享来源。点「查看 Skill」后只预填该目录，继续明确扫描、预览和确认收录；取消返回 Agent，成功进入资产详情。刷新失败保留上次结果并暂停旧入口操作，可用「刷新目录」重试。
- **项目上下文**：项目空间 → 打开项目 → 填写项目内的当前状态 Markdown 路径、可选共同规则路径 →「预览文件」→「保存连接」→「复制项目交接包」。工作台仅保存来源位置，不复制维护第二份项目状态。Agent 中心复用同一连接；复制前重新读取核对，来源变化须重新预览。交接包仅限本机，包含路径和校验信息，不含文件正文，不会发送给 Agent。
- **知识连接**：点「连接知识源」→ 填写名称、Obsidian/Markdown 类型及具体目录 → 勾选本人只读确认 →「确认连接」→「扫描文件」。按文件名或路径筛选，选中文件查看纯文本原文；「复制来源指针」只复制位置和校验信息，不含正文。重新打开需再扫描，已保存的连接保留。目录身份变化时先「重新确认目录」；「断开连接」不删除原文件。
- **正文查询**：扫描后切换「正文查询」→ 输入短语 →「查询正文」。结果显示文件、命中行和片段；有剩余文件时点「继续查询」。点「查看原文」会重新核对文件版本，变化时要求重扫。更换关键词或来源会撤回旧结果。查询限于当前来源，不调用模型；不是语义搜索或知识整理。
- **知识整理**：查看原文 →「加入整理」（可跨来源，最多5份）→ 填写问题、本人确认 →「创建整理任务」。详情中准备或复制任务文本，交给本机的本人 Codex；将返回的 JSON 文件「导入候选」。可查看候选各版本、主张出处、冲突和未知项，点击「核对来源」检查变化。任务可归档、备份和恢复。复制不会启动 Agent，导入不代表结论已确认，也不会写回知识库。遇到“结果待核对”先刷新，草稿和文件保留。
- **候选保存与撤回**：在整理任务选定候选版本 →「核对保存记录」→ 选择已连接的 Obsidian、领域和文件名 →「预览保存」。核对完整位置与全文，勾选后「确认保存候选」；看到「已保存并核验」才是成功。只新建到已存在的 `00 待整理/生活`、`工作/个人` 或 `工作/团队`，不覆盖文件、不正式采纳。重开先核对记录；需要撤回时「预览撤回」→ 明确确认，只移除本次创建且未修改的候选，完整恢复文本仍保留。遇到结果待核对先查记录，切勿重复保存。
- **资产库**：完整 Skill ZIP 导入导出、Prompt 与工作流创建、编辑、版本恢复、收藏、搜索和归档。初始 6 份为示例，可从设置移除。
- **本机 Skill 收录**：资产库 →「收录本机 Skill」→ 核对扫描目录 →「扫描目录」→ 预览条目 →「确认收录」。可核对入口全文、完整文件清单、权限及指纹；预览不入库，确认后才保存快照。相同来源和内容不会重复收录。来源变化或另一页面保存导致冲突时，用底部「重新预览」恢复，已填写名称保留。
- **个人改版**：打开 Skill → 内容预览下的「来源与改版」→「创建个人改版」→ 确认名称。新资产固定记录来源版本，之后可独立编辑，原资产与本机源目录不变；不是同步或覆盖 Agent 的副本。
- **目标副本**：打开 Skill →「目标副本」→「关联已有副本」→ 选择已保存的 Agent 管理目标与固定资产版本 →「查找已有副本」→ 选一个候选 →「预览对比」→「确认关联」。这里只保存对应关系，不安装、不覆盖文件。可重新核对内容/文件/权限差异；资产有新版仍按固定旧版核对。调整至别的版本需明确确认旧映射，解除只删除关联。Agent 管理目标内可直接打开其关联 Skill。
- **版本比较与恢复**：打开资产 →「版本记录」→ 选择查看版本与比较版本。可看历史全文、逐行差异和 Skill 文件变化，导出所选历史版；「恢复此版本」经范围确认后生成新版本，旧历史保留。恢复失败需核对错误并重新确认，不会同步或修改 Agent。
- **工作流固定引用**：新建或编辑工作流 →「引用资产」→ 选择 Skill／Prompt 及确定版本 →「添加引用」→ 保存。上游更新只提示「有新版」，不会自动替换。详情可展开核对引用内容；「复制流程说明」带 Prompt 原文和 Skill 包路径，「导出流程与引用」下载完整 ZIP。含 Skill 时须把 ZIP 一并附给同机 Agent；复制不是安装或执行。
- **Skill 本机交付**：打开 Skill 卡片 →「复制本机安装口令」→ 粘贴到同一台电脑上的 Agent。口令带确定版本的 ZIP 下载链接和 SHA-256；10 分钟有效，工作台服务必须保持运行。展开「本机有效链接」可查看和撤销。云端或远程 Agent 不可用；受限沙箱可能需要下载权限。无法下载时，单独「导出完整 Skill 包」并附给 Agent。
- **设置 → 本地数据**：导出资产、连接和任务备份；选择 JSON 备份后预览并确认合并；可检查旧版浏览器记录。恢复不覆盖当前设置、扫描结果或冲突历史。知识写入与配置变更的恢复记录独立存放，不在此 JSON 内；迁移应保留整个应用 `data/` 目录。
- 随手记、参考库、夜间计划和模型草稿保留编辑功能。知识语义查询、自动编译/写回、飞书知识源、模型调用与夜间执行尚未接通，页面有明确状态。

## 数据与边界

主库位于应用 `data/`，不纳入 Git。每次保存形成独立快照，以 SHA-256 校验并原子更新 `CURRENT.json`。Node 内置 SQLite 仅提供进程排他锁，业务数据仍在 JSON 文件中。清理浏览器缓存不会删除文件主库。

空主库首次打开时优先迁移同源旧 IndexedDB，旧库保持原样；已有文件主库不被其他浏览器旧记录自动覆盖。多页面冲突会拒绝覆盖并保留表单，请先复制未保存内容再刷新。

扫描只读取目录、项目标记、Git 远端和分支；默认深度 6、最多 5,000 目录，不跟随子目录符号链接，排除依赖、输出和隐藏目录。达到上限、权限不足或读取失败会显示不完整/错误，不代表“没有项目”。后续进入显示最近结果，可手动重扫，尚无后台定时扫描。

本地目录逐项区分已发现、缺失、未核实、范围外、未识别和待确认；已登记路径核验与递归共用扫描预算。仅实际检查得到缺失才允许替换，unknown不当缺失。两个已有Current连接的项目不会自动吞并；候选有自己的Current或已知远端不同会保留双方并拒绝合并。预览5分钟有效，确认前复核主库与目录身份。失败或丢失响应先「刷新核对关联」，不自动重放。文件源的项目根和子目录链变化均要求重新预览保存；旧无指纹连接不会自动升级为可信。通用拆分与双Current冲突决策暂未实现。详见 [PROJECT-IDENTITY.md](PROJECT-IDENTITY.md)。

GitHub 只读，最多 1,000 仓库；失败时保留历史。Agent 发现不执行程序、不读取配置正文、凭据或聊天，也不自动安装、修复或修改配置。只有本人在配置管理中明确读取、预览并确认，才对受支持字段执行操作；其他配置不回显或写入。Obsidian、飞书和历史监工服务没有被改动。

Agent 目录检查只读元数据、不保存第二份实例状态；目录存在不等于活动实例或 Skill 已启用，程序版本未核验会明确显示。默认位置与服务进程环境不能覆盖全机所有自定义实例；外部共享来源、项目信任、插件和启用设置未解析。Home/Profile 及祖先链接不跟随，最多 100 个 Profile、1000 项枚举，受阻和截断明确呈现。其他品牌暂仅检测入口。更多边界见 [AGENT-INVENTORY.md](AGENT-INVENTORY.md)。

版本读取限白名单安装元数据，不执行 Agent：Codex 安装包/npm 身份与入口声明、Codex App bundle、Hermes 同 venv 的 Python 包与入口。App 版本不冒充内嵌 CLI 版本，无法取证时显示未核验。管理目标最多100个，绑定是本人选择的管理范围，不是活动实例；选项5分钟有效，保存前复查来源身份及主库版本，提交时再验期限。目标缺失不会自动删除记录，解除不删除源目录。更多边界见 [AGENT-TARGETS.md](AGENT-TARGETS.md)。

配置管理当前支持 Codex 的终端动画/提示、Hermes 的完成提醒/显示推理内容，均为 Home 层布尔设置；缺失值显示未设置，不推断实际默认值。只支持现有 UTF-8 普通单链接文件，最多256 KiB；保留其他字段、注释、换行和普通权限。白名单外字段不编辑，复杂 YAML 引用/合并及不安全权限/链接拒绝。模型/API、凭据、安全策略、Hook/MCP、任意文本编辑、自动重启与采用检查均尚未接入。

每次变更先保存私有操作记录，再替换配置并回读；记录在 `data/config-operations/`，只存受限局部逆向差异与验证信息，不存完整配置，不进入普通资产备份。最多500条操作，暂无自动清理；容量满会拒绝新写入，不删除恢复依据。恢复必须匹配原目标、目录身份、正文与 uid/gid/mode。外部变动需重新读取，不能用恢复覆盖。macOS 默认写入仅精确保留 provenance，遇 ACL、quarantine 或其他扩展属性拒写；不剥除安全标记。不要同时用其他编辑器修改同一配置文件。

若执行时断线，保留本次操作ID并先「核对本次操作」；未确认期间禁止新配置修改，同一浏览器任务重开仍保留此锁。只有可证明尚未开始的拒绝会直接解锁并提示重新读取；未知不当作失败或成功，不自动重放。运行中的 Agent 是否采用仍需该 Agent 的独立验证，本轮未启动任何真实 Agent。完整合同见 [AGENT-CONFIG.md](AGENT-CONFIG.md)。

项目上下文只在明确预览、保存或复制时读取选定文件，每份最多 64 KiB；只支持已发现且仍位于扫描根内的项目、可见路径下的 UTF-8 Markdown 普通文件。不允许上跳、隐藏目录、符号链接、硬链接或特殊文件。`CURRENT.md` 只是默认候选，不代表已找到项目权威；文件内容是否有效仍需本人确认。断开连接仅移除指针，不删除源文件。仅有 GitHub 远端的项目暂不读取正文、不自动克隆。交接包不授予接收 Agent 新的执行权限，复制不等于已接收或完成接手。

知识连接只存来源指针，不持久化来源原文和索引；连接时只检查元数据，扫描仅枚举名称/路径，选择文件、显式正文查询或整理核验才读取正文。最多20个来源，每次扫描5000条目/2000文件/8层，协作式5秒预算，单篇256 KiB；索引10分钟有效。只支持可见的普通单链接UTF-8 Markdown，不跟随链接、隐藏或依赖目录，不执行HTML或外部图片。部分扫描不当作完整，无命中不当作未扫描；刷新失败撤回旧结果。来源变化需重新确认或扫描，未知写入先「刷新连接核对」再判断，不盲目重试。主库备份不能激活其他本机来源权限。没有自动读取真实Vault、语义查询、自动编译/同步或向其他Agent开放。详见 [KNOWLEDGE-CONNECTIONS.md](KNOWLEDGE-CONNECTIONS.md)。

整理任务会保存问题、来源版本指针和本人明确导入的候选正文；候选可能包含私人知识，备份应由本人保管。最多50任务、每任务5份依据/10个候选版本，单候选64 KiB；历史不覆盖。任务文本只有问题、指针、输出格式与边界，不附来源原文；只供本人本机Codex使用。来源核验是当次逐篇观察，不是永久有效、原子快照或结论已核实证明；备份恢复不恢复来源授权。当前提供明确确认后的待整理候选保存，不提供正式采纳、编译页更新或自动执行。详见 [KNOWLEDGE-COMPILATION.md](KNOWLEDGE-COMPILATION.md)。

候选保存的私有记录在 `data/knowledge-writes/`，包含完整候选正文与来源版本，最多250次操作；不自动清理，不进入资产 JSON 备份。每次预览5分钟有效，固定版本、目标目录身份和原文版本；目录缺失、来源变化、过期、链接、同名文件均拒绝写入。排他创建、持久化和回读后才显示成功。已被编辑或同字节替换的文件不能撤回。准备后中断、记录损坏或结果无法确定时会保留文件/记录并阻止重放，部分情形仍需人工核对，不提供通用自动修复。撤回不是一键恢复原位置；需要正文时可从本机恢复全文取回。详见 [KNOWLEDGE-WRITEBACK.md](KNOWLEDGE-WRITEBACK.md)。

正文查询是单个连续短语的大小写不敏感字面匹配，去掉两端空白后1–100个UTF-16代码单元，不支持正则、分词或多词AND。每批最多100次文件尝试、4 MiB预计正文、2秒协作式预算、50个命中文件；每文件最多3段约300字符片段。安全双读实际I/O约为预计正文两倍，系统调用本身不能被时间预算打断。同服务只运行一批查询，忙碌须稍后显式重试；继续查询不自动执行。读取失败或超限会提示未覆盖，断开、过期或身份变化撤回整批结果；无持久化搜索索引、查询词或片段。详见 [KNOWLEDGE-QUERY.md](KNOWLEDGE-QUERY.md)。

Skill ZIP 上限 10 MB，解压上限 25 MB / 300 文件与目录；保留隐藏文件、空目录、可识别的普通 Unix 权限。拒绝越界、路径冲突、符号链接、特殊权限、损坏文件、多 Skill 入口、非 UTF-8 文件名、加密或 ZIP64 包。旧资产权限信息可能不完整，需要原始 ZIP 才能校准；不会猜测或改写历史。结构校验不是安全审计，导入前请确认包中没有不应交付的凭据或私人文件。主库累计包内容上限 64 MB。快照尚不自动清理，请定期导出备份并关注磁盘空间。

本机交付不上传云端，不修改 Agent。链接是仅授权该版本包的临时凭据，勿随意转发；不会进入主库或备份。最多 20 个有效链接、合计 100 MB；到期自动清理，重启全部失效。列表记录是进程内状态，不是长期交付审计。复制、下载请求不证明安装或激活，接收 Agent 仍需询问安装范围并执行准入审查。撤销不会删除已经下载的副本。

工作流最多引用 50 项，每个 Skill／Prompt 选择一个确定版本，不支持嵌套工作流。缺失或归档引用可保留为待修正草稿，但会阻止复制完整说明或导出引用包；修正引用后重试。资料包含流程、Prompt 原文、完整 Skill ZIP 和版本／SHA-256 清单，原始输入合计上限 25 MiB，超限明确拒绝而不截断。通用资料包不是目标 Agent 部署配置。恢复旧工作流也恢复其当时引用；移除示例时会保留被个人工作流任意历史版本或个人改版来源引用的示例。

本机 Skill 扫描不自动启动。默认提供 `.codex/skills`、`.agents/skills`、`.hermes/skills`，可修改为具体目录；最多 20 个根、深度 4、3000 个目录、500 个候选、10000 项元数据。未发现不等于未安装，截断和不可访问明确提示。候选目录别名只在明确根之间解析；完整包不接受包内链接、硬链接、特殊文件或已知认证配置（如 `.env`、`.netrc`、`.npmrc`、`.pypirc`），不会执行脚本。普通隐藏资源、二进制、空目录和普通权限保留。敏感文件名检查不能代替内容安全审查，请勿将含私人信息的包收录或交付。

副本核对限 Codex/Hermes 已保存 Home 的受支持 `skills` 根，不将用户共享、项目或插件目录自动算作该目标的副本。查找只枚举候选，明确预览才读单个完整包；重开显示待核对，不把上次成功当成当前状态。缺少权限元数据时标记部分未核验，内容相同也不证明安装或启用。目标改绑或目录身份变化后旧关系失效，必须重新关联；最多1000条关系，扫描和预览各5分钟、最多20份。主库仅保存指针和确认时指纹，不保存外部副本正文；备份不会激活外来本机关系。

完整预览最多 300 项 / 25 MiB，入口为 UTF-8、最多 100 万字符；每次预览有效 5 分钟，最多保留 20 份待确认预览。确认重新核对真实来源位置、全部内容和主库版本，失败不部分收录；重新扫描或服务重启使旧预览失效。来源记录是历史证据，不代表当前源目录内容、安全性、安装或采用状态。来源新内容另建收录项，不覆盖已有个人改版。

## 常见问题

- 服务不可用：按上方启动后刷新；不会静默重置数据。
- GitHub 未连接：本版复用本机 `gh` 登录；需要授权时由本人完成官方流程，工作台不收集密钥。
- 本次未检出/检测受阻：检查范围和错误后重扫；不会擅自删除旧记录。
- 端口或主库被占用：已有实例时直接打开入口，不要重复启动。
- 来源缺失或发生变化：检查项目内相对路径，重新预览；不要把默认 `CURRENT.md` 当成自动发现的有效文件。复制失败时可选择面板中的交接文本手动复制。
