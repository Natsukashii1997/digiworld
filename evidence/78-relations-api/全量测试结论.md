## 3. CI（Linux）修复后复跑

PR #80 第一次跑 CI 时，`project-relations.test.mjs` 的接口用例失败：`c30` 期望是数字，实际是 `null`。原因是非 macOS 上登记不了项目（卷 UUID，见 `tests/mac-only.mjs`），`inspect()` 不读 git，`c30` 按设计就是 `null`；原有的同类接口测试都用 `macOnly` 在 Linux 上跳过。现在改成按平台断言：macOS 上必须是数字，其他平台必须是 `null`。用例其余部分在两个平台照常跑。

修复后本机全量：1629 项，1627 过、1 败、1 跳过，唯一的失败是第 1 节说的「生产factory」隐藏目录基线（`npm-test-ci-fix.log`）。
