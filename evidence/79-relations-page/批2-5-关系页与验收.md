# #79 批 2～5：关系轨道、支撑流、联动、动效与验收（2026-11-08）

## 改了什么

- `src/ProjectRelations.jsx`
  - **关系轨道**：三圈同心（内圈基础设施 104、中圈能力 200、外圈产品 296，`type` 为 unknown 的放外圈并标「未分类」），每圈按项目数等分角度，起始角和定稿一致；连线是二次贝塞尔，控制点 `C + (中点 − C) × 0.25`；颜色按关系类型，推断和「明确独立」画虚线；节点是胶囊。
  - **信息卡**：没有选中时显示枢纽排行（关系条数前 6）；选中或悬停时显示名称、类型 · 状态、30 天提交 / 上游 / 下游、关系列表（方向箭头、类型、对方、说明 · 出处；来自 AGENTS.md 或技能统计的标「自动读取」，推断的标「推断」）和「在项目总览打开 →」。单个项目 AGENTS.md 读不到时，只在它的信息卡里注明。
  - **交互**：悬停高亮自己和邻居，其余变暗；点击固定选中，再点一次、点空白处或按 Esc 取消；Tab 聚焦节点后按 Enter / 空格选中；信息卡里点对方项目就换成对方；页头关系类型开关会同时影响连线、计数和信息卡。
  - **支撑流**：用 d3-sankey 排「底座 → 产品 → 当前状态」三栏，宽度用 #78 的 `sankey.links`。0 或读不到提交的产品给最小宽度，标签照实写。流带从底座色渐变到产品色，产品到状态从产品色渐变到状态色；标签高于 26px 时写两行，否则一行，都带深色描边。悬停底座高亮它支撑的产品和这些产品的去向；悬停产品高亮整条链；悬停状态高亮流进它的全部链路；悬停流带高亮这个产品的整条链。点产品节点，轨道图会选中它并滚到可见处。卡片底部写分摊规则（取接口的 `sankey.rule`）和目前没有产品接入的底座。
  - **两图联动**：轨道选中或悬停某个项目时，桑基同步高亮：产品高亮整条链，底座高亮它支撑的全部链路，其他类型不高亮。
  - **动效**：进场时圆环画出、连线依次描出、节点弹出、流带淡入，结束后去掉动画类（否则描线用的虚线长度会盖住「推断」虚线）；高亮连线上有 2 个同色光点沿路径流动（SVG `animateMotion`，只在高亮时存在）；桑基高亮流带上有白色细光移动；选中节点外发光呼吸。开了「减少动态效果」时这些全部不做，直接显示终态。
  - 悬停提示组件自己管状态，鼠标移动时图不跟着重画。
- `src/project-relations-palette.js`（新）：项目类型、关系类型、当前状态（键和项目总览「要注意的事」一致）、底座颜色。
- `src/ProjectsSpace.jsx`：`openInOverview`，切回项目总览，复用 `select` 选中对应卡带，并把焦点移到这盘卡带上。
- `tests/project-relations-sample.mjs`（新）：照定稿的 16 个项目和关系，用 #78 的 `buildRelations` 生成和接口同形的合成数据。

## 和定稿、#79 正文不同的地方

1. **左下角提示折成两行，宽度限 300px**：定稿里这行提示压在「牛马之家」节点上。
2. **信息卡不显示「业务域」和「一句话」**：接口里没有这两项，#79 正文也写了「名册里没有就不显示，不要编」。
3. **页头没有「待确认草稿」计数**：#79 正文没有列这一项，接口也没有草稿概念（手写关系以名册为准）。
4. **桑基底座的分摊和定稿稍有不同**：按 #78 接口规则，产品和底座之间任何非「明确独立」的关系都算接入，所以 GitHub 中心通过一条推断的数据流也接到了自建技能库。以接口为准。
5. **配色放在 JS、页签小字用 `--muted`**：见 `批1-页签与骨架.md`。
