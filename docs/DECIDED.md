# 已定内容登记表

用户选定、定稿或验收一个界面、交互、文案、数据格式的当轮，由做这一轮的 agent 在下面加一行，并在当轮交接里写明「已登记 DECIDED.md」。以后判断「这处算不算已定」先查这里，要改登记过的内容先单独问用户（全局规则第 15 节「改动确认」）；网页界面登记时同时留基线截图，之后的基线对比就以这里登记的截图为准。

- 一行一项，只增不删。用户同意改掉某项后，新加一行，旧行的备注写「已被 <日期> 那行取代」。
- 提交号写定下来时的那个提交；没有界面的写「无截图」；在哪定的写得能查到（会话日期、PR 或 issue 编号）。
- 没登记不等于没定：对话、PR、issue 里用户明确说过「就这个」「定了」的，照样算已定，发现了就补登记。
