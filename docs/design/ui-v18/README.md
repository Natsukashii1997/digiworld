## 页面简报

### 基地（原世界总览）

- **这页做什么**：每天从这里开始。决定接着推进哪个项目、处理还没孵化的捕获、拿走常用的资产；想到什么随手记一笔。
- **主角**：出战中的项目（存档槽）和待孵化的蛋。
- **最常做的 3 件事**：
  - 继续一个项目。
  - 孵化一条捕获。
  - 复制一份常用资产。
- **为什么这样排**：主线的捕获、孵化、出战三站都在首屏。记一笔放在待孵化旁边，因为记下的就是新蛋。数字只出现在液晶屏上。

### 资产仓库

- **这页做什么**：找到能用的那一份，直接复制出战，同时看得出它进化到了哪一步。
- **主角**：资产本身，包括类型形象、进化阶段和出战次数。
- **最常做的 3 件事**：
  - 搜索或筛选。
  - 复制。
  - 新建：手写、从捕获孵化、从参照物逆向。
- **为什么这样排**：卡片按出战次数排序；复制按钮直接放在卡片上；8 份资产在首屏全部可见。

## 两个方向

### A · 克制版（按评审 §9 落实）

- **页头**：一行 72px 的页条，放标题、计数、搜索和主操作。去掉了英文眉题、编号、成熟度徽章和导语。
- **质感**：
  - 面板是平的，发光只留给主按钮。
  - 液晶只用来显示数字：待孵化、出战中、本周出战、SLOT 编号。
- **基地**：
  - 左列：出战中、待孵化。
  - 右列：状态屏（小暴龙机加三个读数）、常用出战。
- **资产仓库**：
  - 横向卡片，每行 3 张，屏幕缩成 104px 的小窗，8 份一屏看完。
  - 「新建 ▾」菜单展开示意：手写一份 / 从捕获孵化 / 从参照物逆向。最后一项就是原来的逆向工程（D2）。

### B · 世界感版（保留原版签名）

- **保留的签名**：10/10 否决 v17 时你点名保护的元素都在，包括液晶点阵眉题、38px 大标题、问号和一句导语、橙色光晕、暴龙机中枢、纹章环、数码地平线、屏幕材质卡。
- **基地**：原来的暴龙机中枢构图不动，只换上有含义的内容。
  - A 口是待孵化，B 口是出战中，下方是常用出战。
  - **走线上有信号脉冲，表示有新蛋待孵化**。今天有新记录，所以 A 线亮着。B 线是暗的，因为存档都是最新的。这就是 10/05 你确认过的“走线脉冲 = 需要注意”。
- **资产仓库**：
  - 保留竖向屏幕卡，也就是 10/05 你说“唯一满意”的那一页的形态。
  - 屏幕降到 116px，液晶数字直接标明“出战”，复制按钮放在卡片上。
  - 每行 4 张，8 份分两行。

### 两个方向共用的部分

- **侧栏**：
  - 导航按主线分组：基地 / 捕获（随手记、个人收藏）/ 炼化与出战（资产仓库、项目空间）/ 设置。逆向工程不再有独立入口（D2）。
  - 捕获项后面的绿色数字是待孵化数。
- **蛋屏**：缩成 72px 高的液晶屏，显示待孵化数；季节改为按真实季节的静态画面（D5、D6）。
- **令牌 2.0**：
  - 字号：12 / 13 / 14 / 16 / 20 / 28；B 版另外保留 38px 大标题。
  - 圆角：6 / 10 / 全圆。
  - 阴影：两级。
- **390 宽**：
  - A 版是单列，顺序为状态 → 出战中 → 待孵化 → 常用出战。
  - B 版暴龙机置顶，各个端口依次往下排。
  - 控件的可点区域不小于 44px；小按钮靠外扩可点区域达标。

## 与评审文档的一处冲突，请你定

评审 §9 写的是“去掉英文眉题、编号和成熟度徽章”。但 10/10 你否掉 v17 时明确说过，这些元素就是质感本身。A 版按 §9 做，B 版按 10/10 的保护清单做。你选定后以你的选择为准，并同步回写评审文档 §9。

## 自检记录

1. 收藏封面显示成黑块：服务对 `/collection-media` 返回 `Cross-Origin-Resource-Policy: same-origin`，本地文件页读不到。改为截图时代取封面。
2. A 版基地右列下方大块空白：改成左右两列各自堆叠。
3. A 版常用出战的说明折行：去掉阶段格，改成“成熟期 · 出战 6 次 · 10/16”。
4. B 版卡片描述的两行截断失效：原因是网格把描述拉高了。描述改为 `align-self: start`。
5. B 版首行的孵化按钮竖排并越出面板：修正选择器优先级，并允许按钮收缩。
6. B 版第三条走线穿过了记一笔输入框：去掉这条线，常用出战不接走线。
7. 390 宽时暴龙机里的蛋被放大裁切：缩放规则改为只作用于外壳的 SVG。
8. 横向溢出：四张稿在 1440 和 390 两种宽度下都没有，由 `shoot.mjs` 自动检查。
