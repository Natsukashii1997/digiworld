## 用户的决定

1. **基地和资产仓库都用 B 版**（A 版产物已删，记录留在 `c5b6dab`）。
2. **左下角伙伴屏完全不改**，原样保留：86px 液晶、每 15 秒换季、数码蛋滚动、屏下一行“秋 · 落叶 · 数码蛋”。
3. **全站向伙伴屏看齐，指的是品质标准，不是复刻。** 用户原话：“我指的是从精致程度，无论是创意还是动效还是整体适配，都参考这个标准，而不是说所有的模块都做成和伙伴屏一样的。”交接 630 里“资产卡屏、暴龙机屏、计数窗都改成伙伴屏的浅色液晶”的做法因此撤回。
4. 暴龙机周围的 8 个徽记删掉；动效要在 HTML 里能跑，并配分镜；先做资产仓库一页定方向，再做基地和录入稿。
5. 资产仓库「设计」类型的像素图和录入结构重做（像素图已定 B4 调色板版）。
6. **第二轮最终确认**：三页方向都对；下文四项偏离全部按稿里的做法定下——抽屉 880 两栏、卡面去版本和标签、「编程 Agent 做界面」话术、投递反馈节奏。

## 伙伴屏的标准，拆成 6 条

每一页都按这 6 条自查，各用自己的创意达到，不搬伙伴屏的外观。

| 标准 | 伙伴屏里的做法 | 本轮怎么落到各页 |
|---|---|---|
| 一个完整的创意 | 蛋活在四季小世界里，只负责陪伴 | 资产仓库＝出战与进化；基地＝暴龙机是中枢；录入＝左边每一下改动，右边当场看见 |
| 动效有编排 | 滚半圈→刹住回摆→跳起翻正→落地微压；换季扫描线；冬天积雪 | 都按帧跳变（steps），有蓄力、残影、停顿，不用平滑缓动 |
| 和用户动作有因果 | 复制成功后数据落进蛋里；戳一下有 4 种反应 | 复制、投递、继续、勾选都有看得见的回应，并接回伙伴屏或暴龙机里的蛋 |
| 介质可信 | 整数点距、三级墨色、液晶残影 | 卡屏是 4px 点阵 LED 屏；图标、读数都按整数像素落在点阵上 |
| 适配严丝合缝 | 按容器取整数点距；减少动态时给静止帧 | 390 宽重新编排（不是简单堆叠）；减少动态效果时结果直接到位 |
| 克制 | 屏下只有一行等宽小字 | 卡面信息收敛；去掉常亮的霓虹与无含义的装饰 |

## 各页做了什么

### 侧栏（三页共用）

- 伙伴屏换回原版结构和样式：`.partner` 一节照抄 `src/styles.css`，页面直接引用 `src/partner-lcd.css`，画面由 `src/partner-lcd.js` 原引擎绘制，截图定在秋季。屏上不加任何数字。
- 第一轮那块“72px 待孵化读数屏”和移动端顶栏的小蛋都已撤掉；捕获项后面的绿色待孵化数保留。

### 资产仓库

- **卡屏**：暗色 LED 屏，4px 点阵（3px 灯珠 + 1px 缝），未亮的灯珠隐约可见，上面盖玻璃反光和扫描线。图标按 4px 一格落在点阵上，去掉大片辉光。
- **卡面收敛**：标题、一句话、一行等宽说明（如“Prompt · 成熟期”）和复制。**版本号和标签不再上卡面**，打开详情再看。
- **复制反馈**（[分镜](shots/资产仓库-B-分镜.png)）：
  1. 图标下沉一格蓄力，再按 4px 一格起跳、落地，身后两层液晶残影；
  2. 出战数逐行上滚换成新值（个位先停）；
  3. 数据像素沿现有「数据飞入」飞向伙伴屏，蛋接住（原样）。
  4. 成长期资产**第一次被复制**时再演进化（依据源码口径“成熟期＝成功复制”）：图标闪白两下 → 扫描线从左到右刷过卡屏 → 第三格点亮 → 说明行换成“成熟期”。已是成熟期的资产不演进化。
- 悬停沿用现有效果：背光亮起、图标播放自己的帧动画、扫描带掠过。
- **390 宽**：改成左屏右文的横向紧凑卡，整页从约 2760 降到约 1620（CSS 像素）。

### 基地

- **收敛**：删掉 8 个徽记；暴龙机屏换回首页原版的 stage 引擎（屏上透明按钮照旧能戳蛋）；屏下说明按源码改回“PARTNER · 数码蛋”；两条走线平时暗着；A 面板去掉常亮光晕；常用出战图标改成 2 倍整数像素；持笔数码兽用源码现成的头像裁切（1 倍 40×40）。
- **因果联动**（[分镜](shots/基地-B-分镜.png)）：
  - **投递**：这一行按帧向走线滑出、收起，下一颗蛋补上；待孵化 17 → 16 翻页；A 线亮起，数据点按帧流进暴龙机，蛋接住（引擎原有 `catchData`）；数据点再沿 B 线流到出战槽，收件数 +1 并闪两下。
  - **孵成资产 / 焚决 / 归档**：演到蛋接住为止。
  - **继续**：蛋跳一下（引擎原有 `poke`），数据点从暴龙机流向这个槽。
  - **常用出战复制**：沿用现有「数据飞入」，次数 +1。
  - **时钟**：每分钟只有变了的那一位逐行上滚。
- **390 宽**：暴龙机置顶，常用出战、待孵化、出战中依次往下；窄屏不画走线，只保留计数、列表和蛋的反应。

### 新建设计（录入抽屉，新页）

- **形态**：盖在资产仓库上的右侧抽屉，宽 880。左栏填写 01–05，右栏常驻 06 复制预览。
- **6 个区块**：
  1. 效果图：最多 6 张，第一张作卡面；
  2. 基本信息：名称、一句话、**交给谁**（编程 Agent 做界面 / ChatGPT 生图）、标签；
  3. 风格底座：每次复制都放在最前面；
  4. 招式：名称 + 提示词，勾选的默认一起复制；
  5. 高级（默认折叠）：附设计 Skill 包，保留 10/19 方案 C 的包能力；
  6. 复制预览：风格底座 + 已勾选招式，外面套哪段话由“交给谁”决定。
- **联动**（[分镜](shots/资产仓库-B-新建设计-分镜.png)）：勾上一个招式，勾号分三帧画出，这一段在右栏按帧撑开、闪两帧，“已选”和字数同步；切换“交给谁”，首尾两句逐格擦掉、换成另一套话术。
- **话术**：「ChatGPT 生图」与 `src/design-asset.js` 的 `designPromptText` 一字不差；「编程 Agent 做界面」是本稿新拟的话术，用户已确认采用。
- **390 宽**：录入页占满整屏，标题栏和保存栏贴边常驻，预览接在最后。
- **网格里的设计卡**：有效果图的，屏幕上部放效果图（裁到帖子里的仪表盘截图），下面仍是同一条 LED 读数带，页脚“底座+6招式”，按钮〔复制组合〕；没有效果图的「111」显示 B4 图标，写“还没有效果图，也还没有一句话说明”。

### 设计类型新像素图 B4

调色板，带内部拇指孔；描边用类型色（`currentColor`），调色格为橙、青、绿、黄。稿里在运行时注册为 `SPRITES.DesignV2`，源码 `pixel.jsx` 留到阶段 3 再改。已否决的候选：画笔斜搭版（A）、样张版（C）、左侧缺口版（B2）、带笔版（B3）。

- **偏离交接 630 的定稿细节**（用户已确认，按稿里的做法定下）：
  1. 录入抽屉宽 880、左右两栏（630 定的是约 760 单栏）。理由：单栏时勾选招式看不到预览变化。
  2. 卡面去掉版本号和标签。
  3. 设计卡说明行写“底座+6招式”（紧凑写法，窄屏放得下）。
  4. 「编程 Agent 做界面」话术与基地投递的反馈节奏按稿里的做法。

## 自检记录

1. 示意设计卡的效果图上叠着编号和读数，太乱 → 效果图只占屏幕上部，下面保留 LED 读数带；裁切改到帖子里的仪表盘截图。
2. 390 资产卡页脚被说明行撑出卡片 → 卡片正文列改成 `minmax(0, 1fr)`。
3. 分镜里“闪白”没出现：残影副本也带 `.b-icon` 且排在前面 → 选择器排除残影。
4. 伙伴屏接住的成功扫描线只有 0.26 秒，单帧拍不到 → 改为实拍连拍三帧，图注写明扫描线未拍到。
5. 持笔数码兽是 56×65 的整图，放大后溢出槽卡 → 改用源码现成的头像裁切。
6. 录入页 390 横向溢出 89px：来源标题单行撑宽了抽屉的隐式列 → 抽屉列改成 `minmax(0, 1fr)`。
7. 减少动态效果时基地仍放走线数据流 → 数据流和键闪在减少动态时不放。
8. 全页截图把贴底的保存栏截在页面中间 → 截全页时让它回到页尾（真机上仍贴底常驻）。
9. 基地分镜里“蛋接住”那一帧正好停在静止时刻 → 用 Playwright 可控时钟让引擎与暂停的动画同步拨动，改为放大连拍三帧。
10. 最终：三页在 1440 和 390 下都**无横向溢出**；打开“减少动态效果”后，复制、投递、勾选与切换在三页上都**不起动画、结果直接到位**（`shoot.mjs` 自动检查）。
