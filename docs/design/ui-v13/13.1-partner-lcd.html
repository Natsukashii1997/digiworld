伙伴液晶屏 v13.1 预览

和工作台共用同一份绘制引擎。整块屏是固定点阵（60×26），只有三级墨色；熄灭的点会慢慢褪去，形成液晶残影。

一、左下角伙伴屏

  • 蛋每一帧都按当前角度重新落到点阵上，翻滚时轮廓始终是干净的像素，不会出现斜拉的锯齿。
  • 节奏：滚半圈 → 刹住回摆 → 跳起翻正 → 落地压扁 → 停；停靠点 中 → 右 → 中 → 左。上窄下宽的蛋滚动时会自然起伏。
  • 四季每 15 秒轮换，换季时有一条扫描线从左刷到右。夏天偶尔打闪电（整屏一闪）；冬天蛋停着时头顶慢慢积雪，一滚就抖掉。
  • 鼠标移上去，屏幕像按了背光键一样亮起；点一下，蛋会做一个动作（跳高、转圈、扭一扭、连弹，轮流出现）。

二、首页数码暴龙机

同一颗蛋居中，4 秒一拍：静置 → 左右晃三下 → 轻跳 → 落地闪两点光。点一下也会动。

三、试一试：复制时数据飞进屏幕

在工作台里复制任何资产成功后，几颗数据像素从按钮飞进左下角屏幕，蛋跳起来接住。
