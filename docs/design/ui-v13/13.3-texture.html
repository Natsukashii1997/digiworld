3. 三层材质

现在的卡片几乎都是“深蓝底 + 细边框”，层次靠线条。改成三种有明确用途的材质，层次靠光：

现在的卡片深蓝底 + 1px 边框，所有卡片一样
面板（哑光）放列表、表单、说明。顶部一道极细高光，底部软阴影，不用边框线
数据屏放资产封面、预览、差异。深色 + 细扫描线 + 顶部冷光
液晶只给“伙伴”相关：伙伴屏、数码暴龙机、TRANSFER OK、液晶提示条
规则一　一块区域只用一种材质；材质嵌套最多两层（面板里放数据屏）。
规则二　液晶材质是稀缺的，只属于伙伴和“成功回应”，不拿来当普通卡片。
规则三　发光只给当前焦点：选中导航、主按钮、正在发生的回应，同一视野里不超过两处。

4. 动效令牌

所有动效只从这 4 档时长、3 种曲线里选，保证全站节奏一致。鼠标移到表格上看各档速度。

档位时长用在哪里示意
即时80ms按键下沉、图标跳一格
快160ms悬停、切换、选中
中240ms抽屉、面板、迷雾散开
慢400ms页面进入、强调回应
曲线　标准 (.2,.8,.2,1) 用于一般过渡；回弹 (.34,1.56,.64,1) 只用于“有回应”的时刻；像素内容一律用 steps()，不做平滑插值。
背景循环　同一视野里只保留一个一直在动的东西（伙伴屏）；其余装饰动画在停留 10 秒后暂停。
列表入场　依次入场，每项错开 20ms，最多错开 8 项。
减少动态效果　全部动画停止，只保留颜色和透明度的瞬时变化。
