## 一、主视觉（已确认）

**数码世界：深墨蓝底、像素图标、克制的发光。** 首批六部分（知识仓库 / 项目空间 / 协同 / 智能体群 / 首页）用了“掌机”隐喻，那是因为这些页面本身就是看状态的屏幕。

**用户 2026-10-04 纠正：不要为了统一而模板化。** 每页先问“这页最需要做什么，什么最美观、最有设计感”，再决定形式。统一靠令牌、字体、图标风格和间距，不靠给每页套液晶屏、掌机外壳。**资产仓库现状是用户最满意的一页，作为品质标杆，不改。**也不要走到另一个极端。数码世界元素必须融进页面结构本身，不能往上随手贴小插图（用户 2026-10-04 否定 v14h）。暴龙机外形只用于首页与协同。

## 二、硬性规范

### 1. 复用公共层，不另起一套

- `src/v14.jsx`：`LcdText` / `LcdCount`（点阵读数与开机扫亮）、`useFlash` + `ResultChip`（一次局部反馈）、`DeviceShell`（掌机外壳）、`Corners`、`AgentSprite`、`useReducedMotion`。
- `src/ui-v14.css`：材质 `m-panel`（机身）、`m-screen`（主屏）、`m-lcd` / `lcd2`（液晶）；`sheen`、`data-tilt`、`reveal`；区块标题 `v14-sh` + `v14-sub`（区块字母编号 `v14-idx` 已于 2026-10-05 取消，标题本身足够）；`button.secondary.ghost`。
- Agent 形象和映射只通过 `src/characters.js` 取。
- 令牌：根令牌在 `src/styles.css` 的 `:root`（受保护，不改）；它没有的档位与硬件色补在 `src/ui-v14.css` 开头的 `:root`，只补新名字。
  - 间距用 `--s-*`，取 4 的倍数；
  - 圆角 `--r-xs 4 / --r-s 8 / --r 12 / --r-l 16 / --r-xl 20 / --r-pill`；2–3px 只给像素级小件；
  - 字号 `--fs-micro 10`（只给等宽大写小标）`/ label 11 / small 12 / meta 12.5 / caption 13 / body 14 / read 15 / title 16 / section 20 / display-s 28 / page-narrow 30 / display 34 / page 38`；可读正文不小于 12px；
  - 动效节奏四档 `--t-instant / fast / mid / slow`；1s 以上的循环氛围动画可写字面值。
- **样式层不写圆角、字号、颜色的字面值**（`#fff` / `#000` 除外），一律引用令牌；`tests/design-tokens.test.mjs` 守护。例外只有受保护的 `styles.css`、`silver-agents.css` 与伙伴屏像素调色板 `partner-lcd.css`。
- 银饰页不挂 `.v14`（不进背景微尘与掌机手感，由 ui-v14-browser 守护），但页头、面板、主按钮与全站一致（2026-10-05 用户授权本页进入优化）。
- 不新增色相；暴龙机外壳、按键、液晶等硬件色已集中为 `--hw-*`、`--lcd-*`、`--mint*` 令牌，需要新颜色先在令牌块里登记。
- 主按钮分区色：工作区（资产 / 逆向 / 智能体 / 项目 / 协同 / 夜巡 / 知识）用橙色，生活区（日历 / 随手记 / AI HOT / 学习成长）用青蓝（UI v15 用户确认）。同一页只用一种主按钮色。
- 每页的样式只写在本页的 css 里，选择器限定在该页，不改别页。

### 2. 页面骨架

- 页头一律用 `PageHeading`：编号、点阵眉题、成熟度、渐变大标题、导语、右侧动作。眉题与导语改在 `pages.js`。
- **导语只写一句，不超过 30 字**（资产仓库、日历、银饰保持原样）。只读 / 只存本机 / 需授权这类边界写进 `pages.js` 的 `bounds`，由 `PageHeading` 渲染成页头下方的小标签，“!”开头表示授权门禁；不要在导语和正文里重复。
- 页内的访问 / 隐私说明（`subtle-notice`）是一行灰色注释，全文保留、不折叠、不截断；不要再做成带底色的横幅。
- 全站同一主题：不出现浅色大块（逆向工程的原文纸已改为暗色横格纸）；不用衬线体（AI HOT 已改为全站无衬线）。
- 区块标题可用 `v14-sh`；材质按内容选：卡片、列表、时间线、网格都可以，不强制 `m-screen` / 液晶。
- 设置类、配置类表单不常驻页面，收进抽屉（`Dialog drawer`），页面上只保留入口。
- 空态用整行 `empty-line`，或公共 `Empty` 组件。没有数据就如实写，**不编数据**；缺数据源的元素写“待接入数据”，并登记缺口。

### 2.1 可测的质量线（获奖级自检，`evidence-2026-10-05-claude-165/audit.mjs` 可复测）

- 非等宽可读文字不小于 12px；等宽液晶读数与步骤编号除外。
- 正文段落行宽不超过 44em（约 44 个汉字）；全站开启 `text-autospace`（中英文自动间距）。
- 每页非等宽字号不超过 9 种，且落在令牌刻度上。
- 页面大区块之间统一 48（`--s-7`）；区块标题到内容 16–24。
- 每个可交互元素悬停都有可见变化；位移类反馈在“减少动态效果”时必须有颜色或描边的替代。
- 同类元素同一手感：容器卡片悬停提亮边框（outline），整张可点的卡片再上浮 2px，未选中的分段 / 标签悬停提亮并加淡底。

### 3. 动效

- 保留 v14b 的手感：点阵开机扫亮、按钮像素涟漪、微光与倾斜、阶梯浮现、待机浮动、跑马灯。
- **禁止换页特效和整屏闪光**（用户 2026-10-04 决定）。不得缩放或变形真实内容，测试会在页面一进入时就量尺寸。
- **一次局部反馈**只在操作真正成功时出现一次：液晶窗翻转约 600ms，旁边出现“已更新”。失败和未知用稳定提示，不闪。
- 系统“减少动态效果”时，CSS、SVG、Canvas、JS 动画全部停止，包括运行中切换。
- 文字一律不用 `--faint`（对比度不达标），用 `--muted`。

### 4. 可用性（验收必过）

- 控件至少 44×44。
- 320 / 390 窄屏逐元素无横向越界、无被裁切的内容，不能靠 `overflow:hidden` 掩盖（装饰性跑马灯除外，需对读屏隐藏）。
- axe（wcag2a/aa、21a/aa）0 违规；在自己写的测试里，先等有限时长的入场动画播完再跑 axe。
- 选择类控件用正确角色：多选一用 `radiogroup`，开关用 `aria-pressed`。按钮的可访问名不要与别处的按钮撞名。
- 只改视觉与前端呈现，不改业务逻辑、数据口径、服务端接口和依赖。按钮名和测试依赖的文字尽量保留。确需修改的测试断言逐条写进交接，不得放宽。

### 5. 每页交付物

1. 改动前后对比图：1440 与 390，合成数据；“前”取改动前的 dist。
2. `npm test`、全部浏览器脚本逐个运行、`node tests/visual.mjs <标签>` 全绿。
3. 本页专项测试：44px、320/390 逐元素溢出、axe、减少动态效果（含运行中切换）、局部反馈只出现一次。
4. 交接写明：改动文件及前后 SHA256、断言调整逐条、数据缺口、未做的部分。
