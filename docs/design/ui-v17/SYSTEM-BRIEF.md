## 一、隐喻：主机与卡带

工作台是一台数码主机，每个页面是插进去的一张卡带。

| 部件 | 是什么 | 为什么 |
|---|---|---|
| 机身 | 左侧悬浮的设备外壳（宽 256，四周留 12，圆角 20，塑料材质加分模线和两颗螺丝） | 把“数码世界”从装饰变成结构：外壳是全站唯一用机身材质的地方，页面内部因此可以安静下来 |
| 品牌行 = 卡带 00 | 纹章、“数码世界”、编号 00；点击回世界总览 | 原来的“世界总览”导航项和品牌按钮重复；合并后省出一行，900 高的屏幕才放得下 |
| 伙伴屏 | 机身顶部，约为现在的 1.6 倍（桌面 80 高，手机 72）；四周是深色内框；左框上一颗电源灯 | 打开工作台第一眼看到伙伴 |
| 电源灯 | 绿色常亮表示已保存，黄色闪烁表示保存中，红色表示保存失败 | 取代原来底部的“已保存到本机”文字行，状态信息不丢 |
| 报信画面 | 平时是四季场景加数码蛋；有待处理时屏幕切成反色液晶：大号“!N”闪烁，旁边写“待处理 N 件”；点屏幕打开待处理 | “脉冲只在有事时出现”。没有事时不显示任何数字 |
| 功能键 | 屏幕下方三颗实体键：搜索（带 ⌘K）、待处理（红色角标）、记一笔 | 顶栏取消后，这三个全局入口并入机身 |
| 卡带架 | 01–12 每页一条卡带脊：编号槽、中文名、计数或“规划”；分区之间用槽线隔开，不再写“工作区/生活区” | 编号替代 Lucide 线描图标，统一了图标语言（G8）；分区由编号段自然体现 |
| 插入中 | 当前页的卡带向内容区推进 8px，橙色编号槽发光；内容区标签条左下方有一段同色“触点” | 让机身和页面之间有一条看得见的联系 |
| 系统键 | 设置（13）和存档点（14）做成机身底部的一对药丸键 | 像掌机底部的 SELECT / START；也让卡带架在 900 高的屏幕里不用滚动 |

## 二、页头两档：卡带标签条

所有页面的页头统一压成一行**卡带标签条**：编号、标题（22px）、问号、成熟度（11px 等宽小字）……右端是本页主操作。标签条吸顶，高 76，底部 1px 细线加 44px 橙色触点。

- 去掉：像素英文眉题（ASSET LIBRARY 等）、38px 大标题、导语、边界标签、页面大水印（page-mark）。导语和边界标签移进问号弹层，**内容不删，只换位置**。
- 工具页（逆向、项目、协同、夜巡、知识、日历、随手记、AI HOT、设置、存档点）：标签条下 24px 直接开始主体。
- 展示页（首页、资产仓库、智能体群、收藏、银饰）：标签条在顶端用半透明渐变、不画底线，主角贴着标签条开场；每页的开场方式由各自的页面简报决定（例如资产仓库的开场是类型架加对象墙，首页是暴龙机中枢）。
- 首页：暂按展示页处理；中枢的具体改法放到首页简报里定。
- 390：顶栏本身就是标签条（菜单、编号、标题、搜索、待处理）；页内只保留一行主操作，标题不再重复。

## 三、令牌（数值）

| 类别 | 规定 | 替代了什么 |
|---|---|---|
| 字阶 5 档 | 11 标签 / 14 正文 / 17 小标题 / 22 区块标题与标签条标题 / 40 展示页特大号（只给展示页开场用） | 原来规定 6 档、实际渲染 11–17 档（G2）。**禁止 11px 以下**；等宽英文最小 11px，字距统一 0.12em（编号 0.04em） |
| 节奏 3 值 | 元素之间 12、区块内 24、区块之间 64（另有 4 / 8 作为微调） | 原来区块间距 48–80 不等（G9） |
| 圆角 3 档 | 6 小件 / 12 卡片与面板 / 20 机身与大容器 | 原来每页 9–16 种圆角（G5） |
| 材质 3 种 | 机身（只给外壳）；屏幕（数据对象本身：资产卡封面、液晶、伙伴屏）；面板（一页最多 1–2 块）。其余内容直接放在底色上，用间距和细线分组 | 原来框里套框（G5） |
| 英文用途 | 只保留：编号与类型码（01 / SKL.04）、状态（ACTIVE / 未上云）、真实数据（时间、哈希、路径）。区块标题只写中文 | 原来英文眉题泛滥（G3） |

### 颜色语义表（G4）

| 颜色 | 只用于 | 不再用于 |
|---|---|---|
| 橙 `--orange` | 主操作（每页最多一个实心橙色按钮）、“需要你”（插入中的卡带、触点、报信） | 热度数字、装饰描边、伙伴身份 |
| 青 `--cyan` | 选中态、焦点环、链接 | 主按钮（AI HOT、收藏、银饰、日历的青色主按钮统一改成橙色） |
| 伙伴身份色 | 只出现在伙伴本身（立绘、名字、协同线路） | 页面通用控件 |
| 红 / 黄 / 绿 | 只表示状态：失败 / 待核实 / 正常 | 分类（例如待处理的“主线”改用橙色强调，不用错误红） |
| 中性 | `--text` / `--text-2` / `--muted` / `--faint` 四级 | 硬编码灰（共 92 个硬编码色要收回到令牌） |

## 四、状态组件

1. **降级行**（G6）：区块内一行，44 高：黄色方点、一句人话、右侧“重试”。同一来源的失败**只提示一次**；页面形态不变，受影响的对象变暗（降低不透明度）。禁止整页空白，禁止把系统原文堆成段落。
   示例文案：“日历暂时读不到，今天的安排先不显示。[重试]”
2. **空位**（G7）：空槽的高度跟随内容，不跟随满载时的高度；同一组空位只在第一个上写一次引导语，其余空位只显示编号。
3. **零值**：计数为 0 时退后显示（`--faint`、缩小一号），不使用强调色。资产卡的热度“0”是第一处应用。
4. **截断提示**：可横向滚动的标签行和卡带架，在可滚动方向的末端加 18% 渐隐。

## 五、390 规则

- 顶栏是标签条：菜单、编号、标题、搜索、待处理，高 60。
- 机身改成从左侧滑出的抽屉（宽 300），结构和桌面一致；矮屏时卡带架可以滚动，底部渐隐。
- 页内第一行是主操作，页头最多两行。
- 标签行、分类行一律横向滚动加渐隐。
