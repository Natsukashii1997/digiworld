## 2. 关键设计判断

1. **球 = 贴了胶带的深墨蓝小圆片 + 像素铅笔**。胶带让它一眼读成“便签”；暖黄内环与“正在编辑的那张便签”同色，展开时全亮，成为便签栏的锚点。直径 52pt（命中区 60pt），冷色描边保证在深/浅壁纸上都有轮廓。平时静止，不闪不跳数字。
2. **便签栏 = 窄版便签墙**。最上面是“写一条…”虚线条；下面便签最新在前，纸色/胶带/字色与随手记页一致；窄栏不倾斜以利阅读。点哪条改哪条，原地亮成暖黄，工具条贴在卡底（沿用 390 已确认的“无序/有序/待办 | A▾”）。没有“贴上”按钮，因为自动保存。
3. **“存没存上”只在三处说，且只说结论**：球角状态点、编辑卡右下的一句话、栏底状态行。草稿＝黄，失败/需选择＝红，冲突卡用橙边。文案不出现接口、版本等技术词。
4. **冲突不合并、不覆盖**：别处版本以引文放在上，自己的在下；默认推荐“两条都留”，另一选项“用别处的”。选好之前收起工具条。
5. **位置**：松手吸到最近的左/右边（离边 12pt），上下保留；栏总向屏幕内侧展开，按可用区避开菜单栏和程序坞；按显示器分别记住位置。
6. **栏内只做新建、查看、编辑、勾待办**；复制、炼入、删除去数码世界页面（栏底“在数码世界打开”）。

## 3. 三个行为决定（常浩 2026-10-15 已按推荐确认）

| 项 | 推荐 | 依据 |
|---|---|---|
| 失焦是否收起 | 默认点外面收起；栏头“钉住”后不收起 | 主用法是“记一句就回去干活”，点回原应用即收起省一次点击；自动保存保证收起不丢；需对照别的窗口时用钉住 |
| 置顶 | 球与展开的栏浮在普通窗口之上、所有桌面空间可见；全屏应用中默认隐藏球（快捷键仍可呼出） | 球必须在使用其他应用时可点；全屏看视频/演示时常驻圆球打扰 |
| 快捷键 | ⌃⌥N 呼出/收起（可改）；栏内 ⌘N 新建、Esc 收起、⌘↵ 写完这条、↑↓ 切换 | ⌃⌥ 组合很少被常用应用占用；⌘↵ 与随手记页“写好这条”含义一致 |
