改前

三页各一套，见上表。

A 分段底板

三页都是一条深色轨道，项之间不留缝；选中格亮一层青色液晶光，数字变亮青并微微发光。收藏的「＋ 分组」是轨道末尾的虚线空槽；随手记的竖线在轨道里。窄屏时轨道变宽、项均分折行，随手记在分组处换行，中间一道横线。

好处：最像一个整体控件，和改前的资产仓库最接近。代价：随手记 10 项在窄屏要 3 行。

B 独立按键

每项一颗实体键（收藏现在那种按下会沉的键），选中键青色描边加外发光；数字放进小计数块，平时灰，选中变橙，与侧栏计数块同一套（10-27 定的「平时灰、选中变橙」）。收藏「＋ 分组」是虚线键；随手记两组之间留宽缝加竖线，窄屏在分组处换行。

好处：手感最实，最像机器按键。代价：最占地方——宽屏收藏的「＋ 分组」会被挤到第二行，窄屏随手记要 4 行。

C 下划线标签页

不要底板也不要框，一条基线上排文字；选中项字变亮、下方一道发光的青色液晶线。收藏「＋ 分组」是行末一个灰色文字键；随手记的竖线保留。宽屏三页都一行放下；窄屏只占一行，横滑，右缘渐隐提示后面还有。

好处：最轻、最省高度，页面层级最清楚。代价：窄屏要横滑才看到后几项（随手记藏 6 项、资产和收藏各藏 3 项）；可点的范围不如前两版显眼。

改后（已落代码）

常浩 10-29 选 A，并要求：不分行，放不下就在轨道里横滑；收藏工具栏删掉 Agent 按钮。落地为共用基础件 FilterTabs（src/components.jsx + src/base.css）：三页同一套 44px 分段底板，只排一行，放不下时边缘渐隐、可横滑，选中项自动滚进可见范围；随手记分组竖线、收藏「＋ 分组」虚线空槽保留。
