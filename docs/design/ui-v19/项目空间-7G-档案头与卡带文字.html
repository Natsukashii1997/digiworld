② 卡带文字：三个方向（第一行是现状）

现状走线 0.24 常显，选中提到 0.9 加发光，文字直接压在线上

A · 走线在文字区淡出走线、过孔、流光到文字那一带渐隐到一成，文字下方再浮现；字加一层很浅的投影

B · 文字区渐变暗底板子下半截叠一层从透明到深色的渐变，走线还在，只是被压暗

C · 丝印标签文字放进一块半透明深色小牌，描一圈代表色细边，像板上的丝印标签
