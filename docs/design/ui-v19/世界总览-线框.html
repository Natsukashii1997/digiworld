世界总览 · 三个方向（黑白线框）

只看结构和主次，不代表配色、字体与质感。三版都是数码世界：深色数码空间、液晶读数（点纹）、像素图（斜纹）、数码兽持笔者、数码蛋、存档槽、出战。三版共用同一批真实内容——出战中的项目、待孵化（随手记 + 收藏里还没去向的）、常用出战的资产、记一笔；左下角伙伴屏原样保留。不同的是页面的组织原理和世界观承担什么信息。

方向一 · 主屏（暴龙机即页面）

不再把暴龙机摆在页中央，而是让整个内容区成为暴龙机的主屏：外壳一圈机身边框，顶上一条液晶读数（时间、待孵化、出战中、本周出战），屏里是出战中、待孵化、装备栏。液晶只显示数字，像素图只标类型与持笔者。暴龙机的签名留下了，而且它第一次承载真实信息。

主角出战中的两个存档槽（名字、持笔者、下一步、收件、继续）。顶上三个液晶数是“今天的仪表”。
读法先看仪表，再看屏里：左大块是要继续的事，右窄栏是要处理的蛋，底下一排是常用装备。一屏看全，不滚动。

质感怎么实在外壳与面板不透明、硬边；只有液晶本身亮（它本来就是发光体）；其余不发光、不渐变；文字对比拉高。参考：Linear / Raycast 深色的密度，初代暴龙机 LCD 的克制。
代价最像“仪器”，场景感最弱；“本周出战”要能从已有的复制 / 继续记录里数出来，数不出来就去掉这格。

主角三张队员卡：谁（持笔数码兽）在推进什么、下一步是什么、带着多少收件和装备。
读法先看编队（横向三张），再往下看蛋巢和道具栏。空槽老实画成空卡，不装饰。

代价最“游戏”，气质最强也最容易过头；只有 1 个项目时首屏会显得空（已用空卡处理）；首页没有暴龙机。
