## 3. 必须原样保留的业务语义

1. ~~先预览、后复制~~ **用户 2026-10-24 改为一次完成**：现版第一次点复制会先展开口令、提示"请先预览口令"，不复制；新版去掉这一步，按钮每次一次完成。口令全文默认收起，点开在框内固定高度、右侧滚动条下滑（不撑高框）。见第 6 节决定 1。
2. 复制前**重读项目状态**与**重读工作台**，核对来源、目录指纹、state_id、收件 / 装备 / 手填下一步与预览时一致；不一致就不复制，并提示重新预览。
3. 复制写**操作留痕**（collabLog：kind start、projectId、agent、stateId、收件与装备引用）；留痕失败的"补记留痕"保留。
4. "复制后打开"走现有 `/relay-sessions/open`；打开失败时如实写"口令已复制；打开应用未确认"。
5. 默认伙伴 = 当前写入者，认不出时 Codex（和现版一致）。
6. 读取失败、GitHub 读取失败、本机活动读取失败的 `SourceReadError` 横条保留，放在卡带槽下方。
7. 开新档 = 标为在推进（现有接口）；`pj-flight` 飞入动画保留并改落点为空槽。
