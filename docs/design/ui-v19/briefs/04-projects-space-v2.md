## 4. 数据口径

### 4.1 项目从哪来

- 只认数字分身名册 `projects.json`（路径在设置里配置），按名册顺序排列，置顶的排在最前。
- 目录扫描搬到「设置 · 目录与扫描」，不再决定这页列出哪些项目。
- 名册里有、本机目录不存在的项目，卡带照常显示，要注意的事写“本机找不到目录”。

### 4.2 现在与下一步

- **现在**：取仓库 `CURRENT.md` 顶节的标题、日期和作者。没有 CURRENT 时，取最近一次提交的标题，并注明“最近提交（没有 CURRENT）”。
- **下一步**按顺序取第一条：
  1. 带 `ready-for-agent` 标签、编号最小的开着的 issue
  2. 带 `ready-for-human` 标签的 issue
  3. CURRENT 顶节或头表里写的“唯一下一步”
  4. 都没有时写“顶节没写下一步”
- **过期**：下一步来自 CURRENT，而 CURRENT 的日期早于最近一次提交超过 3 天时，标“可能过期”。

### 4.3 卡带上“要注意的一件事”

按下面的顺序取第一条：

1. 本机找不到目录
2. 待人工验收 N 张
3. 下一步可能过期
4. 未推送超过 10 个
5. 待 Agent N 张
6. PR 待合并 N 个
7. 没有 GitHub 远端
8. 以上都没有时，写最近提交日期

标黄的是第 1、2、3、4、7 条。

### 4.4 实战（新能力，默认关闭）

- **由常浩在设置里开启**（方案 K4）。只读本机会话记录的元数据，只记四样：技能名、次数、日期、会话所在目录。不读、不存对话正文。
- **Claude Code**：统计两类，一是 `Skill` 工具调用，二是用户输入的斜杠命令（排除内置命令）。插件前缀（`plugin:skill`）合并到技能名。
- **归属**：按会话目录归到名册项目，worktree 按仓库名归。
- **Codex**：只统计用户消息里写了 `$技能名` 的次数，单独一行，标“仅参考”。Codex 开会话时会批量读技能文件，读文件不计入。
- **未开启时**：实战段只显示一行“读取会话里的技能使用：未开启”和一个「去设置」链接；页头的调用数和卡带上的技能数显示 `—`。

### 4.5 收录进资产仓库

- 点一行的「收录」后，先预览将要新建的 Skill 卡：名字、来源（安装位置）、首次与最近使用日期。确认后才写入。
- 写入后回读。成功时，数据点飞进伙伴屏，蛋接住，这一行变「已收录」。

## 5. 交互

| 动作 | 结果 |
|---|---|
| 点卡带 | 卡带压下一帧；一道亮光沿走线跑一遍，之后走线保持常亮光晕；档案屏扫描线刷一遍，换成这个项目；读数液晶滚动到位，下一步逐字打出，实战像素格逐格亮起。手机上点完后滚到档案屏 |
| 已置顶 / 置顶 | 切换置顶，卡带重新排序，小橙块闪两下。最多 3 个，超出时回执提示“先取消一个” |
| 项目卡 ↗ | 在 Obsidian 打开 Vault 项目卡 |
| 详情 | 打开现有项目抽屉（位置、GitHub、规则、体检）；悬停提示本机路径 |
| 收录 | 见 §4.5 |
| 其余 N 个 ▾ | 实战逐行展开，再点收起 |
| 刷新 | 重读名册、CURRENT、GitHub 和实战统计；卡带依次闪一下 |
| 设置 | 跳到设置：名册路径、目录扫描、实战开关 |
| 复制接手口令 | 旧功能，行为不变 |

## 6. 状态与异常

| 情况 | 呈现 |
|---|---|
| 名册读不到 | 卡带架位置显示一行原因和「去设置」，档案屏不出现 |
| 某项目 GitHub 读取失败 | 卡带读数写 `ISSUE ?`；读数条那一格写“读取失败 · 重试” |
| 没有 GitHub 远端 | issue、PR 两格写 `—`，下面写“没有 GitHub 远端” |
| Vault 项目卡读不到 | 档案头只显示名字和本机路径，下面写“项目卡读不到”和「项目卡 ↗」 |
| 实战未开启 / 近 30 天没有调用 | 见 §4.4；没有调用时整段只剩一行字 |
| 读取中 | 卡带先按名册画出，读数是暗格液晶；档案屏扫描线停在顶部，直到读完 |

## 7. 动效

全部按帧。用户开了“减少动态效果”时直接显示最终状态，没有走线流光，只保留常亮光晕。

v19 规矩是「按帧、有因果、一次到位；不做常驻的飘动、呼吸、扫描线」，所以：

- 选中卡带时，走线的流光只跑一遍，不循环。
- 常亮光晕是静态样式，不算动效。

## 8. 手机（390）

- 页头计数一行三个。
- 卡带架横向滑动，每盘宽 148px，一屏露出两盘半；选中上浮和下方三角不会被裁。
- 档案屏通栏：目标 / 不做上下排，三个按钮放到标题下方。读数条改两列，第五格占满一行。现在 → 下一步上下排。
- 提交图高 112px，轴上只留首日、中间一个周一和「今天」。
- 实战改单列，像素格放到下一行。
- 控件不小于 44px。

## 9. 用户决定（2026-10-29，都按推荐）

1. **代表色与两字母代号放哪**：名册 `projects.json` 里没有这两个字段，而名册属于数字分身项目。
   - **推荐**：放在数码世界这边一张小表，按名册 `id` 对应；名册里新增、表里没有的项目，代号取名字前两个字母，颜色按 `id` 从 7 色里稳定地取一个。
   - 另一个选项：给名册加 `hue`、`code` 两个字段，要去数字分身那边改。
2. **实战开关的文案与范围**（方案 K4）。
   - **推荐**：设置里一行「读取会话里的技能使用」，默认关闭。说明写一句“只记技能名、次数、日期和会话所在目录，不读对话内容”。
   - 打开时先预览一次：近 30 天会统计到多少个会话、多少个技能，确认后才开。
3. **Codex 点名要不要显示**。
   - **推荐**：显示，单独一行，标“仅参考”。
   - 另一个选项：不显示，只算 Claude Code。
4. **置顶上限**。
   - **推荐**：3 个，和世界总览的项目块一致。
