选版过程（用户 10-24）：三版（读档画面 / 存档条 / 卡带槽 + 读档屏）选**三** → 嫌乱、堆积，三版优化选**剧场** → 嫌不齐、硬拆步骤、热力图太小，再出三版选 **4-1 交接条**。用户定下的原则：**这里的协同本质就是一段口令 → 选交给谁 → 复制，结束**。

## 1. 这页做什么

读档：看清每个在推进的项目停在哪、下一步是什么，把口令交给一只伙伴接着干；或从库里挑一个项目开新档。

## 2. 主角

**读档屏里的「下一步」+ 一个交出动作。** 顶上三个卡带槽只负责"选哪盘"，读档屏一次只启动一盘。

| 元素 | 是什么 | 怎么呈现 |
|---|---|---|
| 卡带槽 | 在推进的项目（最多 3 盘）+ 空槽 | 一行三张：头像、`SLOT 01`、项目名、一盏状态灯（正常写"认领 · 1/5"，读不到写"读不到 CURRENT"，新档写"新档 · 未读"）；顶边一条色 = 持笔伙伴色，读不到为橙红；选中的橙框 + 向下小箭头指向读档屏 |
| 读档屏 | 选中那盘的全貌 | 左：持笔数码兽立绘 + 名牌；右：对话框写**下一步**（最大的一段字），框下一条**交接条** |
| 交接条 | 唯一的出发动作 | 四只伙伴头像（默认当前持笔者）+ 名字、「复制后打开 X」勾选（默认勾上）、橙色主按钮「复制口令，交给 X」 |
| 30 天双轨 | 最近活动 | 整宽两行：Git 一行（青）、CURRENT 一行（绿），每天一格、格上直接写次数，周一标日期、最后一格写"今天"；头上一行写 Git 几天几次、CURRENT 几天、最近一次时间 |
| 短读数列 | 次要状态 | 阶段（五格）、体检（四点 + "3 项正常 / 2 项要处理"）、队伍（收件 · 装备）、存档（未存档超过 7 天才出现） |
| 库 | 全部项目 | 两个分区并排（个人产品 / 业务系统），每行：来源、名字、路径、最近更新、`SLOT 0X` 或常显的「开新档」；四个折叠组一行四片 |

## 3. 最常做的 3 件事

1. **交出口令**：看下一步 → 点一只伙伴 → 「复制口令，交给 X」。一步完成；勾着"复制后打开"就顺手打开那个应用，粘贴发送由用户自己做。
2. **看进度**：换卡带看另一盘；扫一眼 30 天双轨与读数列（阶段、体检、队伍）。
3. **开新档**：空槽或库里「开新档」，项目飞进空槽。

## 4. 信息层级及理由

| 层 | 放什么 | 理由 |
|---|---|---|
| 页头（一行） | 项目空间 · 在推进 / 项目 / 收件待交代三个液晶数 · 右侧"上次读取 01:38" + 刷新、设置两个小图标 | 维护动作退成图标；标题与计数一行，省出首屏 |
| 卡带槽 | 三盘 + 空槽 | 选择器，不承载细节，所以只留名字和一盏灯 |
| 读档屏 · 主区 | 立绘 + 下一步 + 交接条 | 这页唯一要做的事；立绘与对话框等高、名牌与交接条同高（64px），左右上下边对齐 |
| 读档屏 · 底部 | 30 天双轨（左，占满）+ 短读数列（右，240px） | 活动是用户点名要放大的；其余状态只需"一眼知道正不正常"，收成一列 |
| 口令全文 | 对话框右上角"口令全文 555 字 ▾"，展开在框内，固定高度、右侧滚动条下滑 | 下一步就是口令的核心；全文平时不用看，要核对时一点就在原地展开，不另开步骤。交出按钮每次一次完成，不强制先看全文（用户 2026-10-24） |
| 库 | 卡槽架 + 折叠组 | 第二屏；说明句、标签片、长扫描句都收起（悬停看全文） |

读不到 CURRENT 的一盘：对话框写原因与"不代表没有活动"，交接条换成"读不到 CURRENT，修好后才能交出口令" + 看体检 + 重新检查（主按钮）；下面摆出"等着带走"的收件；双轨两行斜纹写"活动未知"；体检写"2 项要处理"（没有远程备份、未提交改动超过 1 天）。

## 5. 视觉理念

**RPG 读档画面 + 实体机器的做工**：插卡带 → 读档屏亮起 → 持笔数码兽站在左边，下一步像对白写在框里 → 选一只伙伴交出口令。世界观元素都对应真实状态：卡带 = 在推进的项目，数码兽 = 持笔者（写入者），四只伙伴 = 可交给的 Agent，液晶 = 真实计数。做工按全站 v19：面板不透明、单层边框、硬边；只有液晶与少量状态灯自己亮；**橙色只给"交出 / 重新检查"这一个主动作**；Git 青、CURRENT 绿两色只用在活动上。

## 6. 动效与微交互（按帧，减少动态效果时直接到位）

| 时机 | 动效 |
|---|---|
| 进页 | 计数从 00 按帧跳到真实数；读档屏扫描线自上而下启动，下一步打字出现 |
| 换卡带 | 卡带按帧压入、小箭头移过去；读档屏重新扫描启动 |
| 点伙伴 | 头像跳一下；按钮里的名字、"复制后打开 X"、口令第一行同时换人并闪一下；字数翻页 |
| 交出 | 数据点从按钮飞向左下角伙伴屏（手机飞向顶栏菜单键），蛋接住；按钮短暂变液晶绿；回执"TRANSFER OK · 口令已复制，交给 X" |
| 口令全文 | 框内按帧展开 / 收起 |
| 重新检查 | 双轨格子逐格扫一遍再落定；结果如实写（仍读不到 + 检查时间） |
| 开新档 | 库里那一行变成卡带按帧飞进空槽，槽亮起，SLOT 与"在推进"计数翻页，侧栏徽标变 |
| 重新扫描 | 库里各行依次闪过，扫描时间更新 |
| 数码兽待机 | 立绘每 2.4 秒上下动 1 像素 |
