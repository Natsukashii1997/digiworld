项目空间 · 三的三版优化

三版优化共用：页头并成一行、卡带只留 SLOT + 头像 + 名字 + 一盏状态灯、少一半边框、橙色只给继续、库里收起说明句和标签片。都能操作：换卡带、继续、选伙伴、复制、开新档、重新检查、重新扫描。

三 · 原稿用户选定的方向：卡带槽 + 读档屏（优化前，留作对照）

优化 1 · 一栏读立绘 + 下一步 + 一排出发（选伙伴、继续）；口令折起；阶段 / 活动 / 体检 / 队伍收成底部一行读数

优化 2 · 主次两栏左边只有持笔者、下一步、继续；右边档案栏用页签一次看一样：口令 / 活动 / 体检 / 队伍

优化 3 · 剧场RPG 读档画面：数码兽站在左边，下一步写在对话框里，右边是游戏菜单（继续 / 换伙伴 / 看口令 / 档案 / 只复制）
