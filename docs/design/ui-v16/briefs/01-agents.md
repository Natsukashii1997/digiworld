# 页面简报 01 · 智能体群（含能力体检）

状态：**用户 2026-10-05 已确认**（会话来源就是 Claude Code、Codex、Hermes、OpenClaw 四位；390 宽角色卡为横向滑动一排）。下一步：像素精灵确认 → 1440 + 390 视觉稿。

## 1. 这页做什么

选一位伙伴，接着做没做完的事；同时是每位伙伴的档案馆。

## 2. 主角与类型

| 主角 | 是什么 | 怎么区分 |
|---|---|---|
| 一段会话 | 要接力的那段对话，自动从本机会话记录里找出最近一段 | 用“谁传出来的”小头像 + 项目目录区分 |
| 伙伴（主力） | Claude Code / Codex / Hermes / OpenClaw | 各自的数码兽像素立绘 + 专属色（橙 / 青 / 紫 / 粉，沿用现有色相） |
| 伙伴（其他） | 豆包工作等其余 Agent | 应用图标做成紧凑行，同样可作接力目标；以后指定了数码兽就升级为主力 |

## 3. 最常做的 3 件事

1. **接力**：确认要接的会话 → 选伙伴 → 预览并复制提示词、打开对应 App。
2. **看某位伙伴的状态**：常驻项目、擅长、内容是否健康。
3. **维护**（低频）：重新检测本机入口、能力体检、配置。

## 4. 信息层级（从上到下）

| 层 | 放什么 | 怎么排 | 为什么 |
|---|---|---|---|
| 页头 | `03` `SELECT AGENT` `部分可用` / **智能体群** ? / 导语“选一位伙伴，接着做没做完的事。” / 标签：`会话只在本机读取` `复制前先预览` / 右侧：重新检测（图标按钮） | 资产仓库同一套页头 | 全站统一语法；重新检测是维护动作，只配一个图标 |
| ① 接力台 | 英文小标 `CONTINUE`；**会话标题**（中文粗、大）；一行元信息：来源伙伴小头像 · 项目目录 · 更新时间（英文等宽）；最后一句话的摘录（灰，最多两行）；文字按钮“换一段 · 共 15 段”“找更早的” | 一块屏幕材质的宽横幅 | 接力是最高频，放第一屏最上；会话是“要接的东西”，标题必须最醒目 |
| ② 选角排 | 英文小标 `SELECT · 带到哪里继续`；4 张主力角色卡（大立绘、中文角色名粗、Agent 名英文等宽、状态“需粘贴”）；其后一行其他伙伴的应用图标 | 横排；选中卡带描边、头顶指示三角、待机动画 | 选角就是派活：选中谁，就由谁接力 |
| ③ 发车条 | 左：“预览提示词 · 1,240 字”（可展开看全文）；右：次要“只复制提示词”，主按钮“带到 机械暴龙兽 继续 →” | 一条横栏，主按钮唯一 | 每次接力的终点，一眼看到会把什么交给谁 |
| ④ 档案 | 选中伙伴的大立绘舞台 + 标签页：**档案**（擅长、成本、常驻项目、备注）/ **内容**（Skill / 插件 / 损坏 / 未读读数）/ **体检**（链接、挂载、副本）/ **配置**（Home、管理目标、本机入口） | 左立绘右信息 | 查阅类信息，按需展开；维护功能收进标签页，不占第一屏 |

文字分工：中文粗字只给“会话标题”和“角色名”；路径、时间、状态码、字数一律英文等宽小字。

## 5. 理念与形象

- **SELECT AGENT 选角画面**：像游戏开局选英雄。接力就是“换人上场”。
- 数码兽按用户设定（见 [DIRECTION 第五节](../DIRECTION.md)），统一朝右，面向下方的档案。
- 会话来源用小头像标出“是谁传出来的”，接到谁手上一目了然。
- “内容”标签页里的读数本身就是一块屏，保留液晶读数；其他地方不用液晶。

## 6. 动效与微交互

| 时机 | 动作 | 为什么 |
|---|---|---|
| 选中角色 | 立绘从脚底逐行像素载入（沿用现有），之后轻微待机起伏 | 选角的仪式感 |
| 切换目标 | 发车条上的角色名像液晶一样翻一次 | 提示“接力目标变了” |
| 复制成功 | 一次“TRANSFER OK”传送反馈（沿用现有） | 确认已完成，只出现一次 |
| 悬停 | 角色卡上浮 2px，会话横幅边框提亮 | 同类元素同一手感 |
| 减少动态效果 | 全部改为描边与颜色变化，无位移、无载入动画 | 无障碍 |

## 7. 390 宽度的取舍

- 接力台全宽；元信息折成两行。
- 主力角色卡变成可横向滑动的一排（自动吸附），其他伙伴收进“更多伙伴”。
- 发车条固定在屏幕底部，主按钮始终可点。
- 档案的标签页可横向滑动；立绘缩小到标签页上方。

## 8. 不放什么

- **派活推荐**：取消。
- “本机应用与命令行入口 · 覆盖 11 种入口……”状态条 → 「?」弹层。
- 内容检查、能力体检的说明文字 → 「?」或各自标签页内的一行。
- 入口发现明细 → “配置”标签页。
