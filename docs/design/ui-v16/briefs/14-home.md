## 5. 理念与形象

“基地”：暴龙机里的伙伴随工作台的使用成长（资产仓库的数码蛋、智能体群的数码兽都在呼应它）。颜色：橙 = 现在 / 行动；青 = 状态 / 完成；红 = 到点 / 主线；其余中性。

## 6. 动效与微交互

暴龙机轻微浮动；便签悬停 / 聚焦摆正；当前时间红线；协同当前站光晕；减少动态效果时全部静止。
