# 页面简报 02 · 逆向工程（第四版 · 一条线）

状态：**常浩 2026-10-14 已确认方向**（“方向确认，等 Codex 释放后落档派单”）。取代 [第三版](02-reverse-v3.md)（双台、证据链、双终点，常浩评“太乱、到处争抢”）；[第二版](02-reverse.md) 为历史。

常浩 2026-10-13/14 的决定：

- 中间做成终端：**工作台直接在本机跑 REA**（不含模型），跑完直接出**可复刻的任务包**。
- 不选伙伴、不选项目，任务包由常浩自己拿去用。
- 主线到任务包为止，另有可选的“存成 Skill”；去掉验收打勾、打分、达标门禁。
- 作品（文字 / 图片 / 网页截图）走同一条线，但没有终端，直接出任务包。
- 一键更新 REA：GitHub 正式发布版，预演 → 确认 → 回读（沿用第三版约定）。
- 不为形式而形式。

## 1. 这页做什么

投入一件好东西，拿到能直接交给 AI 复刻的任务包。软件由 REA 在本机取证，证据摘要写进任务包。

## 2. 主角

| 主角 | 是什么 |
|---|---|
| 参照物 | 软件（本机 Electron 应用 / 调试版 Chrome 里的网站）或作品（文字、图片、网页截图、只有截图的功能） |
| 取证终端 | 只给软件。真实显示工作台运行的 REA 命令和输出 |
| 复刻任务包 | 这页唯一的产出 |

## 3. 最常做的 3 件事

1. 投入一个软件，填想弄懂的功能和线索词，点“开始取证”。
2. 看终端跑完，复制任务包，自己去 Codex / Claude Code 粘贴。
3. 觉得值得沉淀时，点“存成 Skill”。

偶尔：页头读数检查并一键更新 REA。

## 5. 理念与形象

终端是真的在跑东西，所以是一块屏；作品没有可运行的东西，就不放终端。任务包用橙色顶边，和主按钮同色，表示“这是拿走的东西”。

## 6. 动效与微交互

| 时机 | 动作 |
|---|---|
| 运行中 | 输出逐行追加，末尾橙色光标；状态灯橙色 |
| 完成 | 状态灯转绿，任务包区出现（无位移动画） |
| 复制任务包 | “TRANSFER OK” |
| 发现新版本 | 读数文字变橙，“检查更新”变“一键更新” |
| 减少动态效果 | 光标不闪，其余即时切换 |

## 7. 390 宽度

页头读数与主按钮各占一行；标本列表横滑；终端与任务包全宽，终端内文字自动换行；“复制任务包”占满一行。
