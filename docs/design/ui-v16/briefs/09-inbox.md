## 1. 这页做什么

所有需要你处理的事汇总在一个抽屉里，点一条就去对应的地方。

## 2. 主角与类型

| 主角 | 是什么 | 怎么呈现 |
|---|---|---|
| 任务卡 | 一件需要你处理的事 | 标题 + 一句说明 + 发现时间 +“前往 →”（不放来源图标） |
| 三段 | 主线 / 支线 / 情报 | 段首色条与计数；情报默认收起 |
| 建议卡 | 个人说明修改建议 | 支线卡：哪个 Agent 提的、改哪一节、一行摘要；展开为改前 / 改后对比 + 采纳 / 拒绝 |

## 3. 最常做的 3 件事

1. 点顶栏图标看还有什么事。
2. 点一张卡跳到对应页面处理（抽屉关闭）。
3. 采纳 / 拒绝个人说明建议。

## 4. 信息层级

抽屉头（`INBOX` 待处理 + 关闭）→ 计数行“主线 2 · 支线 3 · 情报 4”→ 主线 → 支线 → 情报（收起）。

## 5. 理念与形象

任务告示板：与读档 / 存档 / 选角同一套游戏语言；卡片轻、扫读快。

## 6. 动效

抽屉从右滑入；主线角标轻微呼吸光；采纳后卡片收起；减少动态效果时直接切换、无呼吸光。

## 7. 390 取舍

## 8. 不放什么

大数字、来源筛选、说明小字、“稍后再说”、独立页面。
