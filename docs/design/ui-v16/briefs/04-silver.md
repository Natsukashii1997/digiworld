## 1. 这页做什么

只给自己看的银饰图鉴：喜欢的一堆堆收着当灵感，买到的一格格点亮。

## 2. 主角与类型

| 主角 | 是什么 | 怎么呈现 |
|---|---|---|
| 收藏格（图鉴） | 我的银饰。按品类（项链、戒指、手链……）设目标数量 | 每个品类一排格子：**已收录** = 天鹅绒底上的白色描边剪影；**心愿** = 虚线剪影，标着来源品牌；**空格** = 编号空位 |
| 欣赏墙（灵感） | 别人的好作品，按品牌（作者字段）成堆 | **品牌堆**：同一品牌的照片卡片轻微倾斜、错落叠放，最上面一张露全；各堆在画布上略散而有序地分布 |
| 单件详情 | 一件收藏或一张灵感图 | 卡片“打开”成详情：大图、剪影、名称、品牌、日期、价格（仅收藏）、备注、来源链接 |

## 3. 最常做的 3 件事

1. 买到一件，填进对应品类的格子（上传实物图，自动抠出剪影）；
2. 看收藏进度：哪个品类还差几件；
3. 把喜欢的别人的作品存进对应品牌的那一堆；看到特别想要的，点“想要同款”。

## 4. 信息层级

| 层 | 放什么 | 怎么排 | 为什么 |
|---|---|---|---|
| 页头 | `12` `SILVER` `部分可用` / **银饰计划** ? / 导语“只给自己看的银饰图鉴。”/ 标签：`图片只存本机` `不进备份，也不上传` / 主按钮“收录一件” | 全站页头语法 | 收录是这页最核心的动作 |
| ① 图鉴总览 | 英文小标 `COLLECTION`；大数字 `07 / 12`（已收录 / 目标）；各品类的进度胶囊（项链 3/5 · 戒指 2/3 · 手链 2/4） | 一行，数字最大 | 打开页面首先看到“集到哪了” |
| ② 收藏格 | 每个品类一排：品类名（中文粗）+ `03 / 05`（等宽）+ 格子。格子 = 编号 + 剪影 / 心愿 / 空位 | 排列整齐（“有序”的部分），格子统一大小 | 图鉴的乐趣在“格子被一个个点亮” |
| ③ 灵感墙 | 英文小标 `INSPIRATION`；编辑式大标题（新写，不沿用参考图文案）+ 一行英文小字；画布上分布着品牌堆，每堆下方是品牌名（英文等宽）+ 张数；最近喜欢的那张单独突出，带编号和一个气泡式的“想要同款”操作 | 略散的画布（“散”的部分）：堆的位置错落、卡片轻微倾斜 | 灵感是随手收的，形态也该是松的；和整齐的图鉴形成对比 |
| ④ 回收区 | 一行可展开 | 页面最底部 | 低频 |

文字分工：中文粗字给品类名、品牌堆上的大标题；编号、计数、品牌名、日期一律英文等宽小字。

## 5. 理念与形象

- **图鉴**：收藏格像游戏的收集图鉴。白色描边剪影是“已收录”，虚线剪影是“心愿”，编号空位是“未发现”。
- **灵感堆**：品牌像一叠叠拍立得照片，随手叠在桌上；最喜欢的那张被拎出来，旁边的气泡就是“想要同款”这个动作。
- 深墨蓝底不变（全站基调），银饰黑白照片在暗底上更有金属感；强调色用生活区青蓝，剪影用银白。

## 6. 动效与微交互

| 时机 | 动作 | 为什么 |
|---|---|---|
| 悬停品牌堆 | 最上面一张轻微放大并摆正，下面几张微微散开，露出“还有 n 张” | 提示这是一叠，可以翻 |
| 点击品牌堆 | 整堆像扇子一样展开成一排，可左右浏览这个品牌的全部卡片 | “堆”到“看全”的过渡 |
| 点击单张卡片 | 卡片从原位放大、翻开成详情（从卡片位置展开，而不是凭空弹窗） | 用户要的“卡片打开”的感觉 |
| 收录一件 | 对应空格先闪一下液晶光，再显出白色剪影 | 图鉴“点亮”的成就感 |
| 想要同款 | 灵感卡上的品牌标记飞向对应品类，变成一格虚线心愿 | 把两个区域的关系看得见 |
| 减少动态效果 | 全部改为淡入淡出，无放大、无飞行、无散开 | 无障碍 |

## 7. 390 宽度

- 图鉴总览：大数字加一行可横向滑动的品类胶囊。
- 收藏格：每个品类一排，横向滑动。
- 灵感墙：品牌堆改为横向滑动的一排，每堆仍保持叠放的样子；点堆展开成全屏横滑。
- 详情改为从底部升起的整页。

## 8. 不放什么

- 常驻的上传表单：收录和加灵感都收进抽屉（沿用拖放选图框）。
- 剪影状态说明、存储说明 → 「?」。
- 价格汇总：不出现，只在单件详情里显示。

## 第三版收藏格（2026-10-05，覆盖上文收藏格的格子状态与排布）

- **未上传** = 该品类的**默认剪影**（用户提供的戒指 / 项链 / 手镯 / 吊坠四张图生成，暗灰、不发光），作为“待收录”的占位。
- **上传了自己的收藏** = 那件实物照片自动抠图后的**白边剪影**（明亮、带光晕）。
- **心愿** = 默认剪影的青色虚影 + 虚线框。
- **格子里不放任何文字**（无编号、名称、品牌）；名称等信息在点开后的详情里。
- 排布压缩：左侧大数字“已收录 / 目标”，右侧四个品类两列两行，每行左侧是品类名和计数，格子约 82×98，不换行，超出时在行内横向滑动。陈列框高度约 260px。
- 品类固定为戒指、项链、手镯、吊坠四类，用户不会新建品类（2026-10-05），不需要“新建品类”入口与通用占位剪影。
