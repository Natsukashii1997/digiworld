## 0. 需求共识

**定位**：夜间无人值守的自动化工程。链条：开工检查 → 人定目标与红线 → AI 小步执行 → 环境反馈 → 有限次修正 → 安全收场 → 可核查结果 → 人验收。选任务原则：只放环境能给出可靠反馈的任务；反馈弱的产出只算“建议”。

1. **目标与红线**：每晚睡前托付，可设“持续推进”；不做全自动挑选。验收标准必填，否则不能入队。全局红线（凭据 / 真实 Vault / 推送 / 装依赖 / 合并主线）触碰即整夜停；任务红线触碰只停该任务。
2. **执行**：每任务独立 worktree + 分支 `night/日期-任务`，可本地提交，不合并不推送。每张任务卡选执行者与复核者（Claude Code / Codex），模板带默认（推进项目 = Codex 执行 + Claude 复核）。仅本机 Mac；按队列顺序串行（默认推进项目在前，可拖动）。学习类可联网（只读、不登录、不提交表单），代码类断网。夜间 Agent 在 worktree 内接力，不改主目录 CURRENT.md。
3. **反馈器**：推进 / 测试 = 测试构建结果 + 验收标准逐条；审查 / 漏洞 = 证据或复现 + 另一 Agent 复核；学习 = 来源 ≥ 2 交叉印证 + 写明对用户的价值。
4. **刹车（默认值，可改）**：窗口 23:00–07:00，06:30 后不开新任务；单任务轮次 推进 12 / 轻量 4；连续失败 3 停；连续 2 轮 diff 与测试结果都没变化判卡死；单任务时长 推进 3h / 轻量 45min；每周订阅额度占比 ≤ 20%（按轮次 + 时长 + 限流提示估算，晨报注明估算）；遇 5 小时窗口限流暂停、重置后续跑。推进项目提前达成即停，剩余时间给轻量任务，只写“建议的下一步”。
5. **开工与恢复**：22:00 预告通知（队列 N 个、检查结果）；22:55 开工检查：电源 / 防休眠 / 磁盘 ≥ 10GB / 额度 / 积压 / worktree 可建且主分支不在合并或变基中 / 执行者 CLI 可识别。单项不过跳过相关任务，全局项不过整夜不跑。中断后从最后绿提交续跑，过 07:00 标“中断”。服务整夜运行需系统级常驻拉起——新装常驻任务须用户单独授权。
6. **收场与晨报**：每任务留 最后绿提交（标记）+ `wip` 提交（标记）+ 每轮日志 + 首败 + “从哪接着做”。晨报在夜巡页，待处理抽屉出现“晨报待决策”，07:05 通知。结构：一句话总结（完成 / 部分 / 失败 / 未开跑 + 估算额度）+ 每任务一卡（状态 / 证据 / 决策）；学习产出单列“新发现”。
7. **人验收**：每分支四动作——合并（先查冲突，需确认；冲突转派 Codex）/ 派白天处理（生成派单）/ 今晚接着跑 / 丢弃（分支保留 7 天）。未处理不合并不覆盖，留到下次晨报。同项目积压 3 个未处理分支后，该项目暂停推进，只跑只读类。
8. **第一版任务类型**：测试白天功能、代码审查与漏洞排查、自主深度学习、依赖与安全通告巡检、文档与代码一致性检查、明日简报。后续候选：测试覆盖缺口、性能 / 体积基线；知识库整理（涉 Vault 边界）暂不做。
9. **任务卡**：固定字段 = 项目、类型（选模板）、目标、验收标准（逐条，必填）、任务红线、执行者、复核者、刹车覆盖、联网（随类型）；自由字段 = 背景、参考文件、“不确定时这样做”。模板库每类一份（角色、步骤、反馈器、晨报格式），可复制改写。

假设（用户已确认）：“新发现”本版只在晨报，不写知识库、不接学习成长页。

## 1. 这页做什么

一页覆盖一天里的三个时刻：**睡前**托付今晚做什么并看到开工检查；**夜里**（偶尔看一眼）知道跑到哪了；**早上**逐个决策夜里的成果。最常用的是早上的决策。

## 2. 方向（用户 2026-10-06 第二轮 grill-me 选定）

第一版（时间轴 / 决策卡，`pages/night-a|b|c.html`）被否：太乏味，且把各类产出压成同一种卡、prompt 不可见。用户重述：**自己选今晚做哪类任务 → 各自的 prompt 能打开编辑 → 每类有自己的产出（学习 = 深刻的学习过程与建议）**。

选定：**芯片插槽 + 翻面**（[结构草图](../sketches/night-structures.png)）。
- 主角：**夜巡芯片** = 一类夜间程序（prompt + 产出约定）。7 种：深度学习 / 继续跑项目 / 测试白天功能 / 代码审查 / 依赖巡检 / 明日简报 / 自定义。每种一个色相与像素图符。
- **主机**：今晚 4 个插槽（容量 = 时间与额度），槽位顺序即执行顺序，可拖动换序；槽口 LED = 状态；槽下是执行者数码兽与“今晚补充”标记。
- **编辑芯片**：右侧抽屉。今晚主题（AI 从近期项目 / AI HOT / 随手记提 3 个候选 + 自己写）；Prompt 两层：模板（长期，锁形，需点“改模板”）+ 今晚补充（只用这一次，橙色 = 你写的话）；执行 / 复核者；刹车；验收标准；右侧“明早你会拿到”产出样张。
- **早上翻面**：同一插槽里的芯片翻成产出卡，形态按类型不同（学习 = 洞见引文 + 阅读报告；项目 = 验收 / 改动 / 合并；测试 = 用例 / 缺陷 / 查看报告）；续跑 / 丢弃收进“更多”。
- **学习报告**：全屏阅读，左目录；主题与为什么学 → 学习过程（每步：读了什么 / 得到什么 / 起点·修正·印证·新增·结论）→ 关键洞见（带来源数）→ 对学习 / 项目 / 认知的建议（转随手记 / 转待处理）→ 来源。气质安静；“存进知识仓库”需手动。
- 气质：选芯片区大胆（夜空主机、芯片实体感），阅读区安静。

视觉稿（1440 + 390）：`pages/night-evening.html` 睡前 · `night-edit.html` 编辑芯片 · `night-morning.html` 早上翻面 · `night-report.html` 学习报告；生成脚本 `build/night2.mjs` + `night2.css`。待补：夜里运行中、加载 / 错误 / 空状态、测试报告与分支交付详情页、自定义芯片编辑。
