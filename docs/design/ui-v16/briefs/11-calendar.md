## 1. 这页做什么

在时间轴上给自己排时间，同时看会议与系统安排；TodoList 防遗忘。

## 2. 主角与类型

| 主角 | 怎么呈现 |
|---|---|
| 规划块（“工作台”日历，可改） | 橙色发光色块 |
| 其他日历（只读） | 青色细框 |
| 夜巡窗口 | 紫色虚线 |
| todo（提醒事项“工作台”列表） | TodoList 横带里的小卡片：方框 + 事项 + 提醒时间；到点标“已到点”（红） |

## 3. 最常做的 3 件事

拖出规划块写一句话；扫一眼本周避免撞车；在 TodoList 记一件事并设提醒时间。

## 4. 信息层级

页头（`08` `CALENDAR` `部分可用` / **日历** ? / 导语“在时间轴上拖出规划，旁边别忘了 TodoList。”/ 右侧：周 · 今天切换、翻页、刷新、主操作“新建规划块”；页头下方 WEEK 40 · 日期范围 + 大字年月）→ TodoList 横带（小卡片一排 + 添加框）→ 全宽周视图时间轴（全天行 + 08:00 起；当前时间红线带像素箭头）。

## 5. 理念与形象

调度屏：时间轴是一块数码调度屏，规划块是发光色块；点块弹出详情与编辑（可改的才有编辑）。

## 6. 动效

拖动时半透明预览块；到点 todo 卡轻闪一次并标“已到点”；减少动态效果时直接切换。

## 7. 390 取舍

## 8. 不放什么

选中当天的事件列表、图例行、项目里程碑占位、长导语、弹出式提醒卡、手机闹钟。
