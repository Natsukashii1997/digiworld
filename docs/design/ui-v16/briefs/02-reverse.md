## 1. 这页做什么

把参照物逆推成一份配方，验证 AI 只凭配方就能 1:1 复刻原件，再举一反三，最后炼成 Skill。

## 2. 主角与类型

| 主角 | 是什么 | 怎么区分 |
|---|---|---|
| 参照物 | 你投入的一件好东西 | 四类：`TXT` 文字、`IMG` 图片 / 海报、`WEB` 网页、`FN` 功能。各有类型图标与英文代号 |
| 配方 | 能让 AI 复刻的全部内容，按类型不同 | 见下表；每一项带标记：观察 / 推断 / **已验证**（经复刻证实） |
| 复刻 | 只凭配方做出来的还原品 | 与原件并排对照，由你判定还原度：达标 / 未达标 |
| 举一反三 | 用配方做的新作品 | 作为 Skill 的示例一起入库 |
| Skill | 炼成的产物 | 资产仓库里的数码蛋，越用越成长 |

| 参照物 | 配方里有什么 | 复刻怎么验证 · 打分项 |
|---|---|---|
| 图片 / 海报 | 风格基因：构图、色板（色值）、字体、质感、光影、媒介；带变量的生图提示词与反向提示词 | 只给配方重画一张，与原图并排、滑块对照 · 构图 / 色彩 / 字体 / 质感 |
| 网页 | 设计令牌（颜色、字体、间距、圆角、阴影的数值）、版式网格、组件写法、动效参数；能运行的复刻页 HTML | 运行复刻页，与原网页截图并排或叠图 · 布局 / 颜色 / 字体 / 间距 / 组件 / 动效 |
| 功能 | 流程、状态、数据、边界、文案；验收用例；验证后的实现代码 | 只凭配方实现，逐条过验收用例 · 验收通过率（自动）+ 交互细节 / 文案 |
| 文字 | 结构模板、语气规则、手法、正反例 | 用配方重写同一主题，并排对读 · 结构 / 语气 / 手法 |

## 3. 最常做的 3 件事

1. 投入一件参照物，交给 Codex 逆推配方；
2. 把配方交给伙伴复刻，回来后与原件对照，判定是否达标；
3. 达标后炼成 Skill；需要时先举一反三做一两件新作品。

| 层 | 放什么 | 为什么 |

| ② 工作台头 | `SPECIMEN · IMG` 代号；**参照物标题**（最大）；来源 / 日期 / 编号；五步步骤条 | 先知道“哪件、到哪一步” |
| ③ 对照台（主角） | **原件 ↔ 复刻** 并排：图片与网页可用滑块左右对照。下方是**分项打分**：每项 5 格，由你来打；功能类加一行自动计算的“验收用例通过率”。总分 = 各项折算百分比的平均，到**达标线（暂定 90%，可调）**才能确认“达标” | 1:1 是这页的目标，对照必须是第一视觉；打分让“像不像”变成可比较的数字 |

| ⑤ 举一反三（可选） | 用配方做的新作品缩略图 + 各自的要求一句 | 证明配方能迁移 |
| ⑥ 炼成 Skill | Skill 名、包含的文件清单（SKILL.md、色板、提示词、参照图、示例 ×n）、主按钮“炼成 Skill”；完成后盖“已炼成”印记，并可跳转到资产仓库 | 终点 |

交出去的环节（逆推、复刻、举一反三）都用同一个发车条：伙伴头像（**Codex 第一、默认选中**）+ 任务包预览 + “复制任务包给 机械邪龙兽 →”。截图以本机路径写进任务包，供 Codex 和 Claude Code 直接打开；交给桌面应用时，提示“需要你把 n 张截图一起拖进对话框”，并提供“在访达中显示”。

文字分工：中文粗字只给“参照物标题”和“判定结论”；色值、令牌、代号、计数、文件名一律英文等宽小字。

## 5. 理念与形象

- 逆向工程**孵化新的数码蛋**：每一次炼成都在资产仓库里多一颗 Skill 蛋。
- 对照台像“鉴定台”：左边原件，右边复刻，中间是你的判定。
- 已验证的配方项用青色标记，并带“经复刻证实”的说明，与观察（绿）、推断（黄）区分。

## 6. 动效与微交互

| 时机 | 动作 |
|---|---|
| 对照滑块 | 拖动时原件与复刻左右切换，松手停在原位 |
| 判定达标 | 步骤条推进一格，配方中经验证的项由黄或绿变为青（一次过渡） |
| 复制任务包 | “TRANSFER OK”（沿用） |
| 炼成 | 盖“已炼成”印记（一次淡入） |
| 减少动态效果 | 滑块改为“原件 / 复刻”两个按钮切换；无过渡 |
