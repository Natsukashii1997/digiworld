## 1. 这页做什么

想到就贴一张；没做完的一眼看见；值得反复用的，炼入焚决。

## 2. 主角与类型

| 主角 | 是什么 | 怎么区分 |
|---|---|---|
| 便签 | 一条念头 | 纸色自动取正文**第一个字色**（红 / 蓝 / 绿 / 黄 / 灰；无字色为素色纸）：深色纸 + 主色淡染 + 顶部“胶带”色条 |
| 空白便签 | 记新念头的入口 | 墙上第一张，虚线边、无胶带；聚焦时展开两格宽并提亮为参考图的暖黄 |
| 已炼便签 | 已炼入某卷焚决 | 右上角火焰小印 + 卷名小字；炼入按钮消失 |

## 3. 最常做的 3 件事

1. **记下来**：点空白便签 → 所见即所得输入 → “贴上”或 ⌘↵。
2. **勾待办**：点方框打钩，文字划线；再点取消。
3. **炼入焚决**：便签右下角火焰图标 → 选卷（原 RefineDialog，选中文字则只炼选中部分）。

改已有便签：点正文原地进入编辑，点外面自动保存，Esc 取消。

## 4. 信息层级（从上到下）

| 层 | 放什么 | 怎么排 | 为什么 |
|---|---|---|---|
| 页头 | `09` `QUICK NOTES` `可用` / **随手记** ? / 导语“先把念头记下来；值得反复用的，炼入焚决。”/ 标签：`只存本机` / 右侧不放主操作 | 资产仓库同一套页头 | 空白便签就是第一位的主操作 |
| 筛选 | 全部 n / 待办 n / 已炼 n | 一排选择片，左对齐 | 只三档，数字即状态 |
| 便签墙 | 第一张空白便签，其余按时间倒序 | 瀑布流，每张随机倾斜 ±1°（按 id 定值，刷新不变） | 念头零散、不分先后、随手贴 |

便签内部：左上时间（英文等宽小字）→ 正文（彩字、列表、方框）→ 右下两个图标：复制、炼入焚决（桌面悬停出现，390 常驻）。已炼：右上火焰印 + 卷名。

文字分工：中文正文是主角；时间、数量一律英文等宽小字；页面不放解释段落。

## 5. 理念与形象

- **屏幕便签墙**：深墨蓝屏幕上贴满便签，略散而有序（参考银饰“略散而有序”的手感）。
- 纸是深色的，只淡染主色并在顶上贴一条胶带色条，守住全站“深墨蓝底、克制发光”；**唯一亮起来的是正在编辑的那张**（暖黄提亮，即参考图的手感）。
- 方框：线框圆角方框，勾选后为打钩（不是实心色块），文字划线并变灰。
- 「?」弹层：三种列表、五种字色、`1. ` 快捷输入、⌘↵ 贴上、炼入焚决是什么。

## 6. 动效与微交互

| 时机 | 动效 |
|---|---|
| 贴上 | 新便签从空白便签位置落到第二格，其余顺移 |
| 勾选 | 方框轻弹出现勾，横线从左往右划过文字（约 200ms） |
| 炼入 | 火焰印盖章落下，一次即停 |
| 悬停 | 便签摆正、微抬 |
| 编辑 | 该便签摆正、提亮；工具条贴在便签底部出现 |
| 减少动态效果 | 全部直接切换；所有便签不倾斜 |

编辑器：工具条 = 无序 / 有序 / 待办 | 红 蓝 绿 黄 灰；选中文字点颜色即变色，同色再点取消；行首敲 `1. ` 自动变编号（`- `、`[] ` 不自动转换）。新便签点外面不丢草稿（离开本页才丢）；原地改点外面自动保存、Esc 取消、保存失败退回原文并提示。长便签最高约 320px，超出渐隐，点一下展开；编辑时显示全文。单条上限 20000 字不变。
