# 动效语言（#127，2026-11-25）

按「状态变化」定动效，不按部件定。每个动效都要回答：什么变了、从哪来、到哪去。数值只在 `src/tokens.css`（CSS）和 `src/motion-tokens.js`（JS、framer-motion、Web Animations）两处，`tests/motion-tokens.test.mjs` 核对两边一致，并禁止样式层 `transition` 写字面量时长、漏写曲线。

## 两层

- **交互容器**（面板、抽屉、提示条、折叠、列表、页签）：平滑、跟手、可打断，不回弹。
- **像素元素**（液晶数字、精灵、徽记、扫描线、读取点阵）：保留 `steps()` 逐帧，不改成平滑插值。

## 四档时长

| 令牌 | 值 | 用在 |
|---|---|---|
| `--t-instant` | 80ms | 按下 |
| `--t-fast` | 160ms | 悬停、颜色、图标切换、**所有退场**、反复做的操作 |
| `--t-mid` | 240ms | 屏内位移、展开、页签指示条、首次进场的卡片、提示条进场 |
| `--t-slow` | 420ms | 大面板进场、数字滚动等低频重要变化 |

退场比进场快；反复做的操作不超过 fast；装饰循环（呼吸、漂浮、扫光）不受四档约束，但只动 transform / opacity，减少动效时停。

新写的一次性状态动画（不循环、不是像素逐帧）必须用令牌；现存的专属节奏（开机、进化仪式等）在 `tests/motion-tokens.test.mjs` 的 `ONE_SHOT_ALLOWED` 逐个登记理由，新增例外要写进去并说明。

## 四种曲线

| 令牌 | 值 | 用在 |
|---|---|---|
| `--ease` | cubic-bezier(.2,.8,.2,1) | 进场、悬停：减速落定 |
| `--ease-move` | cubic-bezier(.4,0,.2,1) | 屏内从 A 到 B：列表重排、指示条、小三角 |
| `--ease-in` | cubic-bezier(.4,0,1,1) | 退场：加速离开 |
| `--ease-back` | cubic-bezier(.34,1.56,.64,1) | 只给小徽记、计数弹出 |

`steps()` 只给像素元素；连续进度可用 `linear`。

## 写新动效前自查

1. 这是哪一种状态变化？矩阵里有就照抄，没有再新增一行。
2. 只动 transform / opacity；必须动别的属性时说明为什么。
3. 退场有没有交代？反复操作够不够快？中途再操作能不能接上？
4. 减少动效时，结果是否直接到位、业务状态不依赖动画事件？
