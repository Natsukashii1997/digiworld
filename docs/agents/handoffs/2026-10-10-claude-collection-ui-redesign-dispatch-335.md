## 三、实现结构要求（为什么要深改）

现状根因：收藏组件是上游浅色主题的原版，样式大多写在 `DeskView.tsx` 的内联 `style` 里（如 `rgba(253,252,250,…)`、`#666159`、`borderRadius:13/15/24`），再由 `collection.css` 用大量 `!important` 压成深色，所以呈现得像“打了补丁”。本单要求：

1. 把工具栏、按钮、分组签、新建分组、SetupDialog、阅读器（ExpandedCard）和各类反馈/错误提示的**呈现样式**，从内联 `style` 迁到 `collection.css` 的语义类名，引用令牌；尽量去掉相应的 `!important`。
2. **不动**：画布布局算法（`buildOrganized`、`sr` 确定性随机、堆叠/展开坐标、分栏）、拖拽/Alt 批选/边缘滚动的逻辑、store、HTTP、导入、本地删除流程、配对与 MCP。只换外观和组件位置。
3. 键帽按钮体系只在收藏页作用域内定义（STYLE-GUIDE：每页样式只写本页 css）。新颜色或阴影先在 `ui-v14.css` 令牌块登记。`design-tokens` 测试必须通过。

## 四、逐区规格

| 区 | 规格 | 验收要点 |
|---|---|---|
| Z1 页头 | 用 `PageHeading` 的现有参数：`pages.js` 中 learning 的导语写“把刷到的好帖子摊在桌上，随手分组。”。“?”说明（`help`）讲三件事：怎么收进来（Chrome 插件 / 拖入帖子）、“本地删除”会整理已删除记录并打开访达、“Agent”只复制只读 MCP 配置。右侧主操作是「插件」：生活区青蓝实心键帽，可访问名保持“插件” | 页头语法与全站一致；同页只有一个主按钮色 |
| Z2 控制轨 | 位置是画布容器的上沿（同一圆角容器的顶边），`position:sticky` 吸在顶栏下方，半透明面板底 + 模糊，下边 1px `--line-2`。**左**：分组胶囊——「全部 N」+ 画布上现有的每个分组（名称 + 等宽数字）+ 虚线「＋ 分组」。点分组胶囊等同点画布上的分组签（`setActiveCategory(groupId)`），并把该组滚入视口；点「全部」收起。胶囊和画布展开态双向同步。「＋ 分组」复用现有新建分组动作，可访问名保留“新建分组”。**右**：搜索框（约 300px；占位“搜索 N 条收藏”；有搜索词时旁边显示“找到 N 条”），然后是 Agent 键帽、本地删除危险键帽（红字 + 红描边）。原“收藏画布 / N 条笔记”标题块和画布底部的新建分组按钮删除 | 胶囊多时横向滚动、无横向页面溢出；展开/收起与画布一致；吸顶时不遮挡卡片的可点区域；按钮名“本地删除 / Agent / 插件”保持 |
| Z3 画布 | 点阵工作台：底色约 `--bg-2` 70%，20px 点阵（青 22%，1px），中心椭圆微光（青 7%），1px 内描边，`--r-l` 圆角；390 下点阵 16px。**高度随内容延展**，只设最小高度（约 620），删除 `calc(100vh-…)` 和内部滚动；拖拽边缘自动滚动改为滚动页面 | 六个宽度下所有卡片/堆叠/展开网格的底边 ≤ 画布底边；文档只有一个纵向滚动；drag 专项通过 |
| Z4 分组签 | 键帽样式：4px 圆角、3px 底边键程、`--panel-2` 底。去掉上游的“荧光笔”色条（组名下那条半透明青色块），换成组名前 6px 的青色像素方点。计数用等宽字体。展开态：青色描边，铅笔按钮与签拼成一体（同高、相接） | 展开/收起/重命名/拖动排序在六宽下无遮挡、无裁切；组名单行省略 |
| Z5 相纸 | 尺寸和排版保持 320 定稿。加投影 + 极细高光边，让相纸“落在桌上”。悬停：暂停呼吸，上浮约 4px，阴影加深，一圈极细青边；不缩放、不回正 | 悬停不缩放（沿用断言）；减少动效时只用描边替代位移 |
| Z6 动效 | a. 进页一次：卡片/堆叠从上方约 12px、透明 0 落到原位，错开约 40ms，总长 ≤600ms，结束后再开始呼吸；搜索、展开、数据刷新时不重播。b. 展开发牌：卡片从堆叠位依次移到网格位，错开约 30ms，用 `--t-mid`；收起反向（上游已有布局动画就只调参，并写进交接）。c. 新收藏落桌：导入成功的那张卡出现一次青色光圈（约 600ms）；partial/失败用稳定提示，不闪。d. 键帽按下沉 3px（`--t-instant`）。e. 系统“减少动态效果”时 a–d 全不播，运行中切换也要生效 | motion 专项：a 只播一次、c 只在成功时出现一次、减少动效双向切换；不缩放真实内容 |
| Z7 插件弹窗 | 见视觉稿 01：眉题 EXTENSION + 标题；顶部状态条；三步卡片（①安装插件：路径单行省略 +「复制路径」+「配置 Chrome 插件」；②配对：「生成插件配对码」，生成后显示配对码与「复制配对码」；③在小红书点收藏 / 拖入）；底部危险区「撤销插件配对」。**状态条只显示接口真实提供的状态**（如是否已配对）；没有“上次收录时间”等数据就不显示，不编数据，缺口写进交接 | 按钮名与测试依赖文字保持；焦点陷阱、Esc、44px |
