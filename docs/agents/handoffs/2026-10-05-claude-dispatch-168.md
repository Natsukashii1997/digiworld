### 2.2 页面结构（按视觉稿，从上到下）

| 层 | 内容 | 现有功能的去向 |
|---|---|---|
| 页头 | 页头语法 + 标题旁「?」+ 导语“选一位伙伴，接着做没做完的事。”+ 边界标签“会话只在本机读取”“复制前先预览”+ 右侧“重新检测”图标按钮 | 原“上下文接力”按钮取消（接力上移到页面主体）；原“重新检测”改为图标按钮；原来源条（覆盖 11 种入口…）移入「?」弹层 |
| ① 接力台 | 见契约；有会话 / 找不到会话两种状态；“换一段 n”“找更早的” | 原 `Relay` 对话框的“手动编写”保留为空状态的“手动写一段”与「?」中的入口；“从项目来源生成”并入提示词模板的“项目唯一下一步” |
| ② 选角排 | 四张角色卡（radiogroup）+ `MORE` 其他伙伴；来源标记；选中态 | 原角色卡区 |
| ③ 发车条 | 预览展开 / 收起、字数、“打开 X 后粘贴发送”、只复制、主按钮“带到 X 继续 →” | 新增 |
| ④ 档案 | 左立绘舞台 + 标签页：档案 / 内容 / 体检 / 配置 | **档案**：原角色卡字段与“编辑角色卡”；**内容**：原 `AgentContents` 中该 Agent 的卡与内容检查；**体检**：原 `HealthAudit` 中该 Agent 的部分；**配置**：原本机入口发现、`AgentInventory`、`SkillSourceImport`、旧记录中与该 Agent 相关的部分 |

- 页面不放解释段落：原有的说明文字一律移进「?」或对应标签页里的一行。

### 2.3 接力能力（后端）

- 按契约实现会话列表与正文读取的适配器（Claude Code、Codex 必做；Hermes、OpenClaw 先查官方文档，查不到就如实显示“暂不支持读取”）。
