## 1. 改了什么

- `src/ProjectsV16.jsx`
  - 项目页读一次 `/collection/notes`（状态 loading / ok / error）。收件里的收藏标题与正文从这里取。
  - `SaveCard` 加 `SlotDesk`（收件最多列 3 条 + “还有 N 条”，装备显示固定版本与“有新版”，「调整装备」）；「继续」按钮名不变，旁边小字“带收件 N · 装备 M”（只数未交代、未删除的）。
  - `LoadoutDialog` 由页面状态 `loadoutFor` 打开。
  - `ProjectLaunch`：
    - 口令 = `projectRelayPrompt(item, agent, relayDesk(...))`。是否已交代按**打开发车条时的留痕**算，本次复制写下的留痕不会把收件从这次口令里拿掉（预览与已复制内容一致）。
    - 收件里有待交代的收藏、而收藏没读完或读取失败：口令禁止复制，提示原因。
    - 收件 / 装备段文字变化（新投递、换装备、条目正文改动）即把“已预览”清掉，要求重新预览。
    - 复制前重读 `/workspace`，按同一规则重算收件 / 装备段；与预览不一致就采纳新状态、提示“收件或装备已变化，请重新预览口令。”，不复制、不留痕。重读失败也不复制。
    - 复制成功的留痕带 `inbox`（kind/id）与 `loadout`（assetId/versionId）引用；已删除的条目和资产不带。
- `src/Collab.jsx`：`usePromptCopy.copy` 接受 `inbox`、`loadout`，非空时放进留痕；补记沿用同一 payload。复制失败不写。
- `src/ProjectDesk.jsx`：`deskRows` 的 `collectionNotes` 传 `null` 表示收藏没读到，收藏条目标 `unknown`（显示“收藏未读到”），不当成“原条目已删除”。
- `src/projects-v16.css`：`.pj-desk*`、`.pj-gear`、`.pj-go-note`、`.pj-loadout*`，只用令牌。收件行两行排（标题在上，来源 · 日期 · 已交代在下）；修掉页面已有的 `section + section` 48px 上边距误作用到装备段。
