## 三、第 4 段：迭代 01 · 扫描线动效

标准：动效小样的方案 A（`motion-prototype/index.html`，可以直接打开对照）。

### 扫描线令牌（全站共用，实现为一个共用工具，不在各页各写一份）

| 令牌 | 值 |
|---|---|
| 线 | 2px，`var(--cyan)`，`box-shadow: 0 0 14px 2px rgba(77,227,255,.9)` |
| 拖尾 | 线上方 60px，`linear-gradient(180deg, transparent, rgba(77,227,255,.18))` |
| 缓动 | `cubic-bezier(.4,0,.6,1)` |
| 显现 | 内容 `clip-path: inset(0 0 100% 0) → inset(0)`，与线同步 |
| 成功色 | 伙伴屏到达时扫一次 `var(--lcd)` |

只动 `transform` / `clip-path` / `opacity`。

### 五个时刻

| 时刻 | 现在 | 改成 | 时长 |
|---|---|---|---|
| 切页 | `.main-content` 的 `page-in`：整页先暗、淡入、上移 6px（`styles.css` 约 1332 行） | 去掉淡入和上移；路由变化时主内容区被一道扫描线自上而下扫出。液晶眉题逐字点亮**保留**，和扫描同时开始。页内锚点跳转不触发 | 440ms |
| 悬停 | 屏幕材质卡上浮、描边变亮 | 保留；新增：鼠标移入时一道 26px 光带沿屏幕封面扫过一次（停留期间不重复） | 520ms，延迟 60ms |
| 打开详情 | 资产详情 `drawer-in` 先空白滑入约 0.3s；搜索 `modal-in`；待处理 `ib-slide`，三种不同 | 统一：从触发元素位置拉出 1.5px 青色描边框飞到面板位置（FLIP），到位后面板内容扫描显现；没有触发元素时直接从面板顶部扫描显现。**内容先渲染好再显现，不能有空白帧** | 框 300ms + 扫描 380ms |
| 加载 | 约 20 个组件各写各的：转圈、“加载中…”、骨架、空白 | 区块级统一为液晶点阵读取条：5 行 × 40 列、7px 点、间距 3px，逐列点亮，下方 `READING · 读取中`（11px 等宽，字距 0.24em）；行内小加载用 1 × 8 迷你版。加载完成后内容扫描显现 | 循环 900ms；显现 420ms |
| 成功 | `flyData` 只有资产复制在用 | 所有复制、保存、收录成功都调用 `flyData`（随手记保存、收藏收录、口令复制、配置复制、存档点创建等）；到达伙伴屏时扫一次绿色扫描线。按钮变绿和提示条保持现状 | 到达扫描 260ms |

- 保留待处理角标 `ib-breathe`、背景粒子 `drift` / `world-sweep`。

### 约束

- “减少动态效果”下所有时刻直接切换，不出现扫描线和飞行像素。
- 扫描线只用于这五个时刻。
- 页面专属动效（资产卡 `rise`、日历 `cal-arrived`、设置 `settings-enter`、收藏相纸落桌等）保留；与切页扫描冲突时以扫描为准，并在交接里列出调整。
