## 四类能力的共用授权步骤

在“设置→配置授权能力”先选对应能力。单选只切换能力类型，不会自动开启。若当前为关闭，点“将关闭[能力名]”，让按钮变为“将允许[能力名]”；再点“预览[能力名]授权”，检查仅所选能力及其范围，最后点“确认本次授权设置”。看到“写后回读一致”，并且“当前：已开启”才算授权完成。取消预览不会开启。结束时在同一能力把按钮切为“将关闭[能力名]”，预览并确认，核对“当前：关闭”。已有授权不重复确认无变化的设置。

以下真实常驻动作只由用户本人在 Claude 复验后做；工程回归的 launchctl 全为桩，开发代理没有连接或停启5178。安装配置、launchd加载、进程采用新代码、页面可用分别核对。

4. 点“预览一次连接测试”，应写“一次只读模型清单GET，不生成内容，不自动重试”、固定官方/v1/models地址；点“确认执行这次连接测试”一次。成功是页面出现“写后回读一致”、有原操作编号；这是模型清单GET的连通回执；清单成功不证明选定模型生成额度/权限、实际账单或其他Agent已切模型。
5. 点“读取本机模型操作与用量记录”找到本次回执。成功后旧预览确认按钮应收起；未知只点“查询本次模型操作结果”，刷新后从记录点“查询本次结果”。同一令牌第二次确认410且零新增请求由工程合成专项验证，不要求用户重放已收起的按钮。确认前若明确提示“预览已失效”，取消后重新预览；不验任何单书生成入口。
6. 需要撤销刚保存的凭据时在该凭据操作记录预览回滚→确认：原有凭据恢复或首次新增凭据删除，回读一致；仅关闭模型授权会拒绝新的请求，但不等同删除钥匙串Key。已经发生的GET不能被“退款/撤销网络”伪表述。
7. 完成后关闭模型请求授权。账单字段没来源继续未知，不为成功写0。
