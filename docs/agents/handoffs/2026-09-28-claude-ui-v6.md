## 改动

| 面板 | 内容 |
|---|---|
| 公共 `Steps` 组件（`components.jsx`） | 流程步骤条，只按真实状态标“已完成 / 下一步”。 |
| Skill 收录弹窗（`SkillSources.jsx`） | 顶部步骤条“扫描目录 → 预览完整包 → 确认收录”，按 result、fresh、preview 的真实状态推进；候选卡片左侧加状态色条（可预览为青色，无法完整收录为琥珀色）；完整包预览改为橙色描边的焦点卡片，SHA 独立成块；候选列表可滚动。 |
| 版本对比（`AssetHistory.jsx` 与样式） | **修复 v4 引入的缺陷**：差异行多加了一个 `::before` 伪元素，把正文挤进 28px 的窄列，导致每个字单独成行、加减号重复。现在直接给原有标记着色。文件变化按新增、删除、修改分别用绿、红、青色边条；历史区内的中性说明不再显示成绿色成功框；比较标题改为等宽橙色 `vA → vB`；恢复确认改为橙色焦点卡片。 |
| 知识整理任务（`KnowledgeCompilation.jsx`） | 任务详情顶部步骤条“准备任务文本 → 交给本人 Codex → 回传候选 → 核对来源 → 保存到待整理”。有候选时停在“核对来源”，没有候选时停在第一步，已归档时全部完成。不会推断“已交给 Codex”这类系统无法得知的状态。 |
| 知识选中态（样式） | 选中的知识源和文件改为橙色描边加左侧高光条，不再整块填充褐色。 |

没有改动任何按钮名、字段名、aria 名称和业务逻辑。
