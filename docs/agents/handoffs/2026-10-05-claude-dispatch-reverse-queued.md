## 二、切片 A：配方、复刻与打分

### A1 数据（先写契约 `REVERSE-RECIPE.md`，再实现）

- 记录增加 `type`：`TXT` / `IMG` / `WEB` / `FN`。**旧记录一律兼容为 `TXT`**：旧 `report`（结构 / 手法 / 可复用）映射为文字配方的三块；旧候选与已入库记录保持可读，不改写、不删除。
- 旧“参考链接”（`state.references`）在标本架里显示为“待逆推”（有链接即可），**只读合并、不迁移、不删原数据**；用户开始逆推时才生成新记录。
- 配方：按类型的分块结构（见简报第 2 节）。每项带标记：观察 / 推断 / 已验证；色板含色值，令牌含数值，功能含验收用例列表。
- 伙伴回交：沿用“贴回复 → 解析 JSON”的做法，每类一份严格格式；网页复刻页 HTML 从回复中的代码块提取并存为文本文件。
- 复刻：每次复刻一条记录，包含时间、伙伴、产物（图片由用户拖入；HTML 存为文本）、各项分数、自动项（功能的验收通过率由用户逐条勾选通过 / 未通过得出）、总分、达标线、结论、说明。
- 达标线默认 90%，可在设置中调整；总分 = 各打分项（分值 × 20）与自动项百分比的平均，未打完分不能确认。
- 判定达标后，配方中被复刻证实的项可由用户一键标为“已验证”（青）。

### A2 本机存储

- 参照物截图、复刻图片、举一反三图片：沿用银饰做法，存本机数据目录下的独立文件夹，只存本机、不上传；主库只记引用（路径、大小、SHA256、类型）。格式 png / jpg / webp，单张上限沿用银饰。
- 是否进入完整备份：按银饰现行规则执行，并在交接中写明。

### A3 界面

- 严格按视觉稿：标本架（状态与类型筛选、列表）→ 工作台头（代号、标题、五步）→ 对照台（原件 ↔ 复刻、拖动手柄、分项打分、确认）→ 配方基因卡 → 举一反三 → 炼成 Skill。
- 交出去的三个环节（逆推、复刻、举一反三）用同一个发车条：伙伴头像（**Codex 第一、默认选中**）、任务包预览、按钮“把 X 任务交给 机械邪龙兽 →”。任务包附截图的本机路径；目标是桌面应用时，提示“需要你把 n 张截图一起拖进对话框”，并提供“在访达中显示”。
- 选到不能生成图片的伙伴做海报复刻或举一反三时，如实提示，不自动替换。
- 取消四列看板；“投入参照物”表单收进抽屉（类型、链接、贴文字、拖入截图、你看重的点）。
