# Claude → Codex｜宽屏右侧大片空白修复

输入 **WB-20260929-53** → 认领 **WB-20260929-54** → 完成（并入 **WB-20260929-55** 登记）。执行者 Claude；日期 2026-09-29。

## 问题

用户报告：网页全屏后，所有页面的右侧都出现大片空白。

原因有两处：
- `.main-content` 设置了 `max-width: 1320px`，但没有居中，屏幕宽于约 1540px 时，右侧就会留空。实测 1920 宽时右侧空约 420px，2560 宽时空约 1060px。
- 视觉脚本只测到 1440 宽，所以一直没有发现。

## 修复

改动 `src/styles.css`：
- 新增令牌 `--content-max: 1760px`。主内容区宽度上限改为这个值，并通过 `margin-inline: auto` 居中。
- 顶栏和保存错误提示的左右内边距改为跟随内容区计算，保证与页面内容左右边缘对齐。
- 智能体群卡片由 `auto-fill` 改为 `auto-fit`，最小宽度设为 260px。Agent 数量少时，卡片会均分整行，不再在右侧留下空列。

结果：
- 1680 和 1920 宽时，内容铺满，右侧只剩正常的内边距（29 至 40px）。
- 2560 宽时，内容居中，两侧空白对称。

## 回归防护

`tests/visual.mjs` 做了两处改动：
- 测试宽度增加 2560 和 1920。
- 每个页面检查主内容区左右空白：左右必须对称，并等于“内容列宽度减去宽度上限”的一半；读不到令牌时按 1760 兜底。

红灯验证：在排除了 `data/` 的隔离副本中，把样式还原为修复前的版本，新检查报出 20 个问题（10 个页面 × 2 个宽度），见 [visual-red-on-prefix-css.log](evidence-2026-09-29-claude-ui-widescreen/visual-red-on-prefix-css.log)。

第一次尝试红灯验证时，检查因为读取令牌得到 NaN 而没有生效。已补上兜底值和对称规则，重新验证通过。
