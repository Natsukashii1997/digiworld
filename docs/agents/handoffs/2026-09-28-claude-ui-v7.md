## 用户要求（本轮原话要点）

- 用户给当前 UI 打 60%，要求再做一轮深层优化：
  - Skill 图标改成像素数码蛋，工作流图标重新设计。
  - 侧栏品牌改成“像素风中文 + 英文 + 符号”，不放数码蛋。
  - 各页面嵌入背景符号，增加层次。
- 提供了数码暴龙机参考图：总览页的暴龙机要更精细，屏幕里的数码蛋形式保留，外层样式重做。
- 总览页“没有层次感和呼吸感，重复乏味”，要求深度优化。
- 提供八大纹章参考图：**不要自己原创纹章，按参考图做**。
- 提供像素素材：八颗数码蛋（先给了一张小图，后给了清晰图纸）、滚球兽 25×28 图纸，以及亚古兽、暴龙兽、机械暴龙兽类、猛鬼兽、滚球兽等较大图纸，要求“好好利用起来”。

## 改动

| 范围 | 内容 |
|---|---|
| 数码蛋 ×8（`pixel.jsx` 的 `egg1..egg8`） | 按清晰的 68×37 图纸逐行转录：外形 14×16，配色取图纸色号，花纹逐格对应。`glyphOf(asset)` 按资产 ID 稳定哈希，给每个 Skill 分配一颗蛋，卡片、详情、总览列表保持一致；Prompt 和工作流不受影响。 |
| 滚球兽 | 按 25×28 图纸逐格转录，替换原先的手绘版本。 |
| 勇气之纹章 | 按像素参考图生成 17×17 点阵，用作侧栏品牌标志。**删除了自创的同心菱形纹章**；首页背景纹样也改成勇气纹章的点阵版。 |
| 八大纹章环（`CrestRing`） | 勇气、爱心、光明、诚实、友情、纯真、希望、知识，按参考图画成霓虹线稿，配色照原作，环绕暴龙机，依次轮流发光。 |
| 霓虹数码暴龙机（`DigiviceArt`） | 按参考图画成矢量线稿：带卡扣的外壳、双线描边加光晕、旋转的数码文字环、电路纹边框、方形液晶屏、左一右二三枚按键、天线。屏幕里仍是像素伙伴或数码蛋。 |
| Prompt / 工作流图标 | Prompt 改为 16×12 的对话框，有文字行，悬停时光标闪烁；工作流改为三节点加箭头的流程链，悬停时节点依次点亮。 |
| 品牌 | 勇气纹章 + `PixelText`（把中文画到画布后硬切像素，得到真正的点阵“数码世界”，带橙色硬投影）+ `◆DIGITAL·WORLD` + 闪烁的液晶光标。服务端渲染时退回普通文字。 |
| 背景层次 | 每个页头右上角放一枚 LED 点阵纹样（每个像素画成小圆点，低透明度）：资产库是蛋，Agent 是机器人，项目是文件夹，知识是书，随手记是铅笔，版本是分支，参考是扫描框，夜间是月亮，设置是齿轮。另有全局漂浮的像素小符号层。 |
| 总览重编排（`Home.jsx`） | 首屏左侧：标题、按钮、伙伴卡片（进化线）；右侧：纹章环加暴龙机，两圈轨道。数据改为开放排布的大数字，只用细线分隔。主线改为“进化轨道”：发光的线串起像素节点，有流动光点。区域按主次重排：“能力”两张大卡片带真实细分数据，“连续性”三张中卡，“管理”四项压缩成侧栏列表，和“最近迭代”并列。 |

没有改动按钮名、字段名、aria 名称和业务逻辑；`digital-world-ui` 测试的断言仍全部成立。
