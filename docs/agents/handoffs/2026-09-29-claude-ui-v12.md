## 过程中发现并修复的问题

1. **侧栏装不下**：导航增加后，在 1000px 及以下高度的窗口里，伙伴和保存状态被挤出视野。处理如下：
   - “待处理”从侧栏移除，与用户确认过的导航预览保持一致，入口放在顶栏和今日页。
   - 导航列表改为自己在内部滚动，品牌、搜索、伙伴和保存状态固定可见。
   - 窗口高度 ≤1040px 时，收紧分组标题的间距，并收起伙伴像素屏，只保留阶段和进度。
   - 实测：900 和 1000 高度下完整显示；760 和 800 高度下只有导航内部滚动，保存状态始终可见。
2. **手机上首屏被裁切**：今日页放大暴龙机舞台的规则覆盖了原来的窄屏规则，在 390 和 320 宽度下文字和按钮被裁掉。现在只在宽于 640px 时放大；400px 以下隐藏舞台，伙伴信息仍在伙伴卡片里显示。
3. **规划中页面右侧留空列**：两张小卡片改为单独成一行、均分宽度。
4. **我引入的运行错误**：精简 App.jsx 的图标导入时，误删了 `Folder` 和 `ScanLine`。搜索面板一旦显示项目或参考结果，就会报错 `Folder is not defined`。已恢复这两个导入，又对 3 个组件文件的 JSX 标签与导入做了逐一核对，没有其他缺漏。这个问题是由 `search-browser.mjs` 发现的，首次失败日志保存为 [search-browser-first-pass-Folder-bug.log](evidence-2026-09-29-claude-ui-v12/search-browser-first-pass-Folder-bug.log)。
