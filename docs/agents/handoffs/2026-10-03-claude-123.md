- **换台**：v14b 预览是把整块面板 scaleY 压成一条线再展开。落地首轮发现这会在 420ms 内压扁真实布局，首页 A/B/C 键在此期间量到不足 44px（见“六”）。改为一层固定在内容区上的亮线覆盖层收线再展开，真实内容沿用原有 `page-in` 淡入、不缩放；播完覆盖层隐藏。视觉同为 CRT 换台，布局与点击区域全程稳定。
- `src/v14.jsx`（新增）：`LcdText`（5×7 点阵，补了 Q Z . · : / + ? ! # % ( ) & 字形）、`useCountUp`/`LcdCount`（0 → 目标值，首帧即从 0 开始）、`useReducedMotion`（监听运行中切换）、`useFlash` + `ResultChip`（一次局部反馈；减少动态效果时只静态出现“已更新”，不加翻转类）、`DeviceShell`、`Corners`、`AgentSprite`（头像 = 头部裁切 1×、名册 = 全身 1×、档案 = 全身 3×；无素材时字母牌）、`Motes`（46 颗像素微尘，30fps，页面隐藏或减少动态效果时清空停画）、`useV14Interactions`（涟漪、微光、倾斜、阶梯浮现；每次事件读取偏好）。
- `src/characters.js`（新增）：角色 → 像素图、Agent → 角色的唯一数据处。
- `src/pixel.jsx`：`Pixel` 增加 `scale`（整数倍原色）与 `crop`（头像裁切），旧调用不变。
- `src/components.jsx`：`PageHeading` 眉题改点阵字（银饰页保持文字）。
- `src/App.jsx`：主区非银饰页加 `v14` 类与 ref；挂背景微尘、换台覆盖层、全站手感。
