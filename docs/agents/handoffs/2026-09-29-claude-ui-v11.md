## 审查中自查发现 → 处理

- 延续三卡被拉高后中间大片空白 → 加主数字（项目数 / 知识源 / 草稿条数，读不到显示“—”）+ 底部分隔线说明，形成“标题–大数字–说明”层次。
- 主线说明换行不均（“…上下 / 文”）→ 去掉 18ch 限宽，平衡换行，现均为单行。
- 知识中枢“文件列表/正文查询”“进行中/已归档”用了橙色主按钮 → 切换不是主操作，带 `aria-pressed` 的按钮统一改为分段控件样式（选中项：深底 + 橙色下划线）。仅 CSS，标记不变。
- **本轮自身引入并修复的缺陷**：替换进化线样式时误删了整段霓虹暴龙机样式（首页暴龙机变成黑块、蛋被放大）。已恢复，并在 `tests/digital-world-ui.test.mjs` 加入关键视觉模块样式存在性断言（暴龙机、纹章环、进化方块、伙伴屏、标志英文、侧栏胶囊、总览行、空状态），做过变异验证：删掉样式后测试失败，恢复后通过。原视觉脚本只查溢出与报错，抓不到这类问题。
