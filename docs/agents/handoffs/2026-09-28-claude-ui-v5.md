## 改动

| 范围 | 内容 |
|---|---|
| `tests/visual.mjs`（新） | 可反复运行的视觉基线：合成数据下 10 页 × 4 个宽度（1440/1024/390/320）加 6 种关键状态，同时检查横向溢出和页面错误。不属于 `npm test`。 |
| 提示分级 | `notify(message, tone)`，tone 分 success / info / warning / error，14 处调用已按语义标注。失败提示显示独立图标、红色描边、留 8 秒，不再显示对勾。消息文字放进独立元素。提示条不拦截点击，只有关闭按钮可点。 |
| 进行中状态 | `Scanning` 组件：液晶雷达扫线加“SEARCHING”，用于项目和 Agent 扫描；不使用 role=status，避免和已有状态区冲突。 |
| 进化演出 | 改为不拦截点击，保存后可以立刻继续操作，Esc 可关闭。 |
| 项目空间 | 按扫描根目录分组，并有“仅在 GitHub”“其他位置”两组；路径显示为相对根目录；嵌套项目按层级缩进并注明“位于「X」之内”（扫描目录本身不算父项目）；Current 已连接显示成功徽章；“身份待确认”“本次未检出”显示警告徽章；扫描不完整显示警告条。筛选、计数、行的类名和数量都不变。 |
| Agent 中心 | 每个 Agent 有独立的像素字母标识（由 ID 派生稳定色相）；证据阶梯“检测到程序 → 管理目标 N → 受控配置”全部按真实数据点亮，Codex/Hermes 未设目标时显示“设目标后可受控配置”；抽屉顶部三项“未验证”显示为琥珀色虚线芯片。 |
| 资产详情 | 新增“交给 Agent”区块：按资产类型列出三步流程，并注明“复制不等于已安装或已使用”。原有按钮和交付逻辑不变。 |
| 知识 | 顶部加四阶段工作流：连接、查询、整理、维护。每段显示真实计数和权限边界，点击跳到对应区域（新增锚点 `#k-sources`、`#k-compile`、`#k-maintain`）。 |
| 夜间模式 | 新增“真正运行前还缺什么”六项清单（依据 PRD N01），全部标为规划中。 |
| 拆解与参考 | 笔记输入提示改为“看到了什么 / 我的推断 / 打算怎么用”。 |
| 其他 | 总览计数器任何宽度下都不留空格；导航名“模型与设置”保留。 |
