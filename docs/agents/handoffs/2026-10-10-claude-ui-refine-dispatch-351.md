## 总约束：保护原版质感

以下元素**一律不动**：页头（编号、液晶点阵眉题、成熟度、38px 标题、问号、导语、边界标签）、侧栏（像素品牌字、导航、伙伴液晶屏）、屏幕材质卡、首页暴龙机中枢、协同地铁图、夜巡芯片、橙色光晕、背景粒子、相纸桌面、AI HOT 报纸版式、存档点时间线。

- 新出现的元素沿用原版已有的组件、字体、颜色和材质，不引入新风格。
- 每条改动都要能在前后对比中看出来；看不出差别的就不做。
- 44px 控件、窄屏无横向溢出、outline 焦点、减少动态效果，这些既有守护保持不变。
- 不读真实 Vault、凭据或 Agent 私人会话；截图一律用合成夹具。只有批 0 的删除涉及真实数据，且只在批 0 规定的范围内操作。

## 批 0 · 删除银饰计划（先做，后面三批都不再碰银饰）

**代码与界面**
- 去掉：`pages.js` 的 `silver` 注册项、侧栏入口、`App.jsx` 路由与 `ICONS`、`Home.jsx` 的银饰摘要（`silverSummary`、图标映射）、`PageHeading` 里的银饰特例、`App.jsx` 里的 `route !== "silver"` 粒子条件。
- 删除：`src/Silver.jsx`、`SilverV16.jsx`、`silver.js`、`silver-v16.js`、`silver-v16.css`、`silver-sprites/`；`server/silver.mjs`、`silver-cutout.mjs`、`silver-cutout.jxa.js`、`silver-schema.mjs` 及 `/api/silver/*` 路由；`tests/silver-v16-*`。
- **注意：`src/silver-agents.css` 被 `AgentRoles.jsx` 引用，是智能体档案的样式。** `tests/silver-agents-*` 测的也是智能体角色卡。先核实，只删银饰部分；必要时改名为 `agent-roles.css`，再同步 import 和测试。
- 共享模块 `server/schema.mjs`、`merge.mjs`、`full-backup.mjs`、`reverse-media.mjs` 只删银饰分支。删除后，旧数据里残留的 `silver` 字段要能被安全忽略或清理，不能让导入、合并、备份报错。
- 站内搜索、旧链接 `#silver` 落到首页（或 404 提示），不能白屏。

**真实数据（不可逆，常浩已明确授权）**
- 删除前记录：`data/silver/` 的文件数、总字节（审计时约 4.2MB）、主库当前 revision，以及 `state.silver` 中 wall / items / wishes / categories 各自的条数。
- 删除：`data/silver/` 整个目录，以及主库中的 `state.silver`。通过正常的写入路径完成（revision 递增、写后回读），不直接改库文件。删除后回读确认目录不存在，`state.silver` 也不存在。
- **不删、只列清单交回**：`data/snapshots/`（135 份历史快照）、完整备份、导出文件里的银饰副本。项目规则要求保留固定版本和恢复留痕，这些副本是否处理，由常浩单独决定。
- **不在范围内**：独立的“银饰计划”项目目录（交接 315 提到的独立工程）；收藏页里常浩自建的“银饰”分组。两者都不能动。

**验收**：侧栏少一项，其余卡带顺序不变；首页没有银饰残留；全量测试通过；`data/silver` 不存在；数据的前后计数和 revision 写进交接。
