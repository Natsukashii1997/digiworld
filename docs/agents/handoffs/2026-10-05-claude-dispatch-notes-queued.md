## 二、要做的事

### 2.1 存储（不变）

- 仍存 `md1`：`[文字]{red|blue|green|yellow|gray}`、`- ` / `1. ` / `- [ ] ` / `- [x] `。旧记录（含非 md1 的纯文本）照常显示与编辑。
- 新增 `md1 ↔ 编辑器文档` 双向转换：`serialize(parse(x)) === x` 对所有合法 md1 成立（规范化差异只允许尾随空白，需在交接中列出）。
- 已知限制保持现状并写进契约：用户在正文里**字面输入** `[字]{red}` 会在保存后被识别为字色（md1 无转义语法）。

### 2.2 所见即所得编辑器

- 记新念头与原地修改**共用同一个编辑器**（建议 `contenteditable` 受限实现，不引入新依赖；如需依赖须先问用户）。只允许：段落、无序 / 有序 / 待办列表、五种字色。
- 粘贴一律按纯文本插入；拖入、富文本、图片、链接都不产生新结构。输入法组合（IME）期间不触发快捷转换与保存。
- 工具条：无序 / 有序 / 待办 | 红 蓝 绿 黄 灰 | ⌘↵ · 贴上。选中文字点颜色即变色；**同色再点取消**；无选区时点颜色则之后输入的文字用该色。列表按钮沿用“已是该列表则取消”。
- 快捷输入**只做**行首 `1. ` → 有序列表；`- `、`[] ` 不自动转换。
- 编辑器内的待办方框可直接点击勾选。
- 390：五个颜色收成一个“当前字色 A ▾”按钮（点开为色板弹层，键盘可达、Esc 收起），工具条一排；⌘↵ 提示隐藏；工具条吸附在键盘上方。

### 2.3 便签墙

- 页头：页头语法 + 标题旁「?」（内容：三种列表、五种字色、`1. ` 快捷输入、⌘↵ 贴上、炼入焚决是什么）；边界标签只留“只存本机”（`pages.js` 去掉“写入 Obsidian 需授权并预览”）；右侧不放主操作。
- 筛选三档：全部 / 待办（正文含任一 `- [ ]` 或 `- [x]`）/ 已炼，带数量。原“未炼”“有任务”取消。
- 墙：第一张空白便签（虚线、“一个念头、一个问题……”、`⌘↵ 贴上`），其余按时间倒序瀑布流；1440 三列、≤1180 两列、≤760 一列（顺序保持时间倒序）。编辑中的空白便签横跨两列并提亮暖黄。
- 便签：纸色取正文第一个字色（无字色为素色）；顶部胶带；左上时间（英文等宽）；倾斜 ±1° **按便签 id 确定**（刷新不变）；已炼 = 右上火焰印 + 卷名（卷已删除显示“卷已移入回收区”），炼入按钮消失；长便签超出约 320px 渐隐 +“展开全文”。
- 操作：右下“复制”“炼入焚决”两个图标，桌面悬停 / 聚焦出现，≤760 常驻。点正文进入原地编辑（点在方框上只勾选，不进入编辑）。
- 保存：新便签“贴上”或 ⌘↵；点外面不丢草稿（本页内存，离开页面丢弃）。原地编辑点外面自动保存、Esc 取消；保存失败退回原文、便签描红一次并提示“没保存上，已退回原文 · 重试”。勾选沿用“先生效、失败退回”。
- 炼入焚决：保持现有 `RefineDialog` 与“选中文字只炼选中部分”的逻辑与正文转换（去色留文字）。

### 2.4 取消“写入 Obsidian”（用户决定）

- 去掉随手记里的“写入 Obsidian”入口与“更多”菜单；`VaultWriteDialog` 组件因个人说明提案仍在使用，**保留**。
- 服务端 `vault-write` 的 note 能力、既有写入回执与 `pendingNotes` **不删不改**；若其他页面（如待处理）还引用随手记写入状态，逐处列出并说明去向，不静默删数据。

### 2.5 动效

- 贴上：新便签落到第二格、其余顺移；勾选：方框轻弹 + 划线从左到右（约 200ms）；炼入：火焰印盖章一次；悬停：摆正微抬；编辑：摆正提亮。
- `prefers-reduced-motion: reduce` 时全部直接切换、**所有便签不倾斜**（视觉稿为展示倾斜未写这条，实现必须写）。

### 2.6 样式

- 把 `v16.css` 随手记一节移植为新文件（如 `src/notes-v16.css`），作用域限定本页；颜色、圆角、字号只用令牌（`tests/design-tokens.test.mjs` 守护；视觉稿里的 rgba 字面值需改为令牌或 color-mix）。旧 `notes-v14.css` 中不再使用的规则清理掉并在交接中列出。
