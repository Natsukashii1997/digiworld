## 改了什么
- **分节标题**（`SecH`）：序号芯片 + 中文标题 + 英文小字 + 细线；现在 / 下一步 / 近 30 天提交 / 实战各一个代表色。
- **现在**：除标题外，给 CURRENT 顶节里“- 键：值”的关键几行（按 来由 → 做了什么 → 测试 → 发布 → 遗留 各取第一条，最多 4 条；“★ 来由：”嵌在同一行时拆开；没有来由类时用标题下第一段说明），再列顶节之后两节的标题与日期。服务端 `parseCurrentTop` 新增 `facts`、`leftover`、`earlier`。
- **下一步**：原顺序（ready-for-agent → ready-for-human → 顶节「下一步：」→ 头表）之后，再取顶节「遗留」（写“无 / 没有”不算），仍没有就由读数推出：推送 N 个本地提交 → 合并 N 个 PR → 分流 N 张 needs-triage。下面列未推送 / 待合并 PR / 开着的 issue 三项；没有明写的下一步时提示“在 CURRENT 顶节写一行「下一步：…」”。
- **近 30 天提交**：横向热力条（一格一天，深浅按当期最多那天分四档，周末空格更暗，峰值格写数字，今天橙框）；下方四个读数：最多的一天、最长连续、本周对比上周、有提交的日子平均，右侧图例。
- **实战**：左侧前三领奖台（第 1 名像素皇冠 + MVP 金色，2、3 名带 V 形绶带的银 / 铜奖牌，数字挖空）；右侧第 4–10 名，满 7 行时均分领奖台高度、上下线对齐；「其余 N 个」与 Codex 点名在通栏虚线下（其余在右）。
- 旧版现在 / 柱状图 / 两列技能列表的样式已删。顺带修：手机宽度下页头三个计数有两三位数时会撑出屏幕（PR #13 起），改为标签可换到数字下面。
