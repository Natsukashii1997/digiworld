## 二、要做的事

- **布局**：左侧 7 个分类（名称 + 一行状态）+ 右侧分组列表；390 分类为顶部横向滑动胶囊。分类：授权与安全（默认）/ 数据与备份 / 项目与存档 / 知识与 MCP / 日历与提醒 / 资讯 / 学习书架。
- **授权与安全 = 权限表**：一项一行（能力、影响范围、状态点、最近一次使用、操作：预览开启 / 撤销 / 管理），开启与撤销沿用现有“预览 → 备份 → 确认 → 回读 → 留痕”流程，**不改授权语义**。行项：写入 Obsidian Vault、知识开放给 Agent、存档点写入、日历与提醒事项、写真实 Agent 配置、模型 / API 连接、常驻服务、夜巡真实执行（暂缓）。新增三项（知识开放、存档点写入、日历与提醒）以对应派单落地的能力为准，未落地前显示“未接入”，不伪造状态。“最近一次使用”取自各能力的留痕；无记录显示“从未使用”。
- **一站式 + 快捷入口（用户决定）**：各分类集中呈现所有设置；项目空间设置抽屉、知识源抽屉等各页入口保留，**读写同一份设置**（同一接口、同一 revision），任一处修改另一处即时一致；不新增第二份存储。
- **数据与备份**：主库位置与大小、REV、最近完整备份 + 立即备份；恢复 / 合并导入 / 导出（沿用 `StoragePanel` 语义）；移除演示资产。
- **项目与存档**：扫描目录、停滞阈值、未存档提醒（黄 1 天 / 红 3 天，供存档点与待处理使用）。
- **知识与 MCP / 日历与提醒 / 资讯 / 学习书架**：分别承载对应页面的设置（知识源开放与排除文件夹、MCP 地址与接入配置；日历权限与“工作台”日历 / 列表；AI HOT 开关与间隔；书架文件夹）。
- **去掉**：模型连接意向草稿（`state.model` 草稿数据保留不删，交接说明）、说明段落（进「?」）。
