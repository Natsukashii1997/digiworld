## 一、页面简报（收藏 · 8 栏）

| 栏 | 内容 |
|---|---|
| 做什么 | 把在小红书上刷到、值得回看的帖子摊在一张桌上，随手分组、再找回来读 |
| 主角与类型 | 主角是**相纸卡**（一条收藏），其次是**分组堆叠**。类型靠分类标签区分，不靠颜色块 |
| 最常做的 3 件事 | ① 扫一眼桌面，点开一张读；② 拖进分组或展开分组；③ 搜索找回 |
| 信息层级及理由 | 页头（是什么）→ 工具条（搜索最重）→ 画布（相纸是视觉重心）。画布是主体，页面其余部分要安静 |
| 理念与形象 | 相纸摊在数码世界的**点阵工作台**上：白纸框是实物，点阵和微光是数码世界的桌面 |
| 动效与微交互 | 已有：呼吸浮动、悬停轻抬、展开时其他组退后。补三处“一次性”动效：进页、展开发牌、新收藏落桌。不加循环背景动画 |
| 390 取舍 | 工具条换行、画布随页面纵向延展；不出现画布内部的第二个滚动条 |
| 不放什么 | 解释段落（说明放进“?”）；重复标题；为装饰而加的插图 |
