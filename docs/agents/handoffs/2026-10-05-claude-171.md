## 一、为什么重新出发

用户对 165/166 那轮“按卫生指标优化”的结果不满意：“越改越失去目标”，只有**资产仓库**满意。经 grill-me 定位：之前从样式出发，没回答“这页做什么、主角是谁、为什么这样排”。资产仓库好在形态源自内容本质（逐条记录 → 一屏一屏；类型形象来自用户概念：Skill = 数码蛋，用了会成长；Prompt = 对话框），以及层级手艺（粗细、大小、中英、动效、几乎无解释文字）。

方法共识全文：[docs/design/ui-v16/DIRECTION.md](../../design/ui-v16/DIRECTION.md)。要点：

- 统一的是**视觉基调与规范**（深墨蓝底、有来由的像素图标、中英双层文字、克制发光、数据对象用屏幕材质；页头语法照用资产仓库并在标题旁加「?」；页面不放解释段落）；每页找最适合自己的呈现，可以有创新。
- 每页同等认真（项目优先级不用于 UI 分级）；v15 只当素材，不作起点。
- 每页流程：**页面简报（8 栏）→ 用户确认 → 1440 + 390 视觉稿（数据丰满为主，另画空、加载、错误等状态）→ 用户确认 → 落代码**。
- 分工：小页 Claude 自做；大页派 Codex，前提是视觉稿画清所有状态；Codex 交回视觉稿 vs 实现的叠图与逐区差异，Claude 逐区验收；同类页返工两次以上改由 Claude 自做。
- 理念来源：用户有想法的页用户先说，没有的 Claude 提两个候选。
- 顺序：智能体群 → 逆向工程 → 学习成长（**用户要求先跳过**，放到最后）→ 银饰 → **随手记（下一页）** → 项目空间 → 知识仓库 → 版本归档 → 待处理 → AI HOT → 日历 → 夜巡 → 协同 → 设置 → 首页 →（学习成长）。

长期记忆已写入：`ui-page-purpose-first`（UI 改版从页面目的出发，逐页简报 → 视觉稿 → 代码）。

### 2.1 智能体群（简报 01）关键决定

选角即接力：顶部接力台（自动找最近会话、换一段、找更早）→ 四张数码兽角色卡即接力目标 → 发车条（预览提示词、只复制、主按钮“带到 X 继续 →”）→ 档案四标签（档案 / 内容 / 体检 / 配置）。取消派活推荐。会话读取只限 Claude Code、Codex、Hermes、OpenClaw；只在本机、先预览、只用于接力；提示词规则生成不调模型；“带过去”第一版 = 复制 + 打开应用。390 角色卡横向滑动一排。

角色设定：Claude Code = 机械暴龙兽、Codex = 机械邪龙兽、Hermes = 亚古兽、OpenClaw = 加布兽（用户图纸 `docs/design/ui-v16/refs/*.webp`；精灵 `sprites/sprites.json` 由 `build/sprites.py` 生成，头部统一朝右；**亚古兽与加布兽等高**；机械暴龙兽少量杂点保留）。此前“机械系图纸是否为机械邪龙兽”已结案（一律用新图纸）。契约：[RELAY-SESSIONS.md](../../../RELAY-SESSIONS.md)。

### 2.2 逆向工程（简报 02 第二版）关键决定

逆向 = **1:1 复刻**：把参照物逆推成配方，验证 AI 只凭配方能复刻原件，再举一反三，炼成 **Skill**（资产仓库里的数码蛋）。步骤：投入参照 → 逆推配方 → 复刻验证（必经）→ 举一反三（可选）→ 炼成 Skill。四类参照物：文字 TXT、图片 / 海报 IMG、网页 WEB、功能 FN；截图由用户贴入、只存本机。复刻验证 = **分项打分**（每项 5 格；功能类加自动的验收通过率；达标线暂定 90%，实践中再调）。交给谁沿用选角头像，**Codex 排第一并默认选中**。标本架左列；入库只留“已炼成”印记。代码仓库与 Skill 的逆向不做。Skill 目前只支持文本文件，图片以媒体清单 + 本机文件实现（派单切片 B）。

### 2.3 银饰计划（简报 04）关键决定

理念为**图鉴**。**灵感墙（欣赏墙）在上为主体**：按品牌（作者字段）成堆、略散而有序；悬停散开、点击展开成扇（其余变暗）、点击单张从原位放大成详情；主推卡带编号与“想要同款”气泡。两块**不设名称与标题文案**，以装饰分隔线（细线 + 刻度 + 银色菱形）+ 陈列框区分。收藏格固定四类：戒指、项链、手镯、吊坠（**不会新建品类**）；**格子无文字**；三态：未上传 = 用户给的默认剪影（暗）、已上传 = 实物白边剪影（亮）、心愿 = 青色虚影；陈列框压缩到约 260px。保留深色底；参考图 [NorChaos](../../design/ui-v16/refs/norchaos-silver-reference.webp) 只借版式风格，文案另写。剪影 `sprites/sil-*.png` 由 `build/silhouettes.py` 生成。
