- **走线与信号脉冲**：四块屏以直角圆角走线接到暴龙机两侧按键；**仅当该屏有需要注意的事时**显示脉冲（B 有主线 = 红、C 轮到人等待 = 橙、D 有超过阈值未存档 = 黄；A 有到点 todo 时可用红色，需在交接中说明取舍）；悬停 / 聚焦一块屏时其走线与边框高亮。走线坐标随布局计算（不得写死像素导致错位），1180 以下隐藏。
