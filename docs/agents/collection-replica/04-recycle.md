# 收藏回收整理

用户2026-10-09授权：收藏页集中整理先前软删除笔记到一个本地地址，允许用户在访达自行永久清理。此票为单一可验证增量，不扩大为自动磁盘清扫。

- 收藏库唯一根不变：`data/collection/`；回收目录 `recycle/日期_标题_独立回收ID/`。未来删除先进入待整理记录，不立即永久删除。
- 整理全部只处理保留的删除快照。每次删除有独立ID，重复收藏和多次删除不混淆；活跃版本、模型、没有删除快照可证明归属的历史版本不移动。
- 同盘 rename 原媒体，不复制或硬链接。每条含已删除标识、人可读正文/OCR/转写与机器快照。整理完成后原状态只留摘要与恢复索引，正文唯一完整快照在回收文件夹。
- 先持久化计划及完整快照，写入并校验文件，再移动，最后提交摘要；中断后基于计划和真实文件核对，不覆盖、不盲目重放。部分成功逐条留痕。
- 已整理目录被人工删除/移走后标记未找到，不猜测永久删除、不自动重新生成。单个文件缺失或变更标记不完整，拒绝伪造完整恢复。
- 恢复需完整校验并反向移动；同ID已重新收藏或目标版本已存在时拒绝覆盖。页面未保存分组草稿阻止恢复。
- 恢复成功不自动删除任何导出快照：媒体移回在用库，原目录仅剩文字历史快照供用户手动清理，不属于当前删除记录。访达“移到废纸篓”仍占磁盘，用户清空废纸篓后才真正释放；应用不会清空废纸篓。
- 打开接口仅接受回收ID/根目录，不接受客户端路径。拒绝路径穿越、链接、硬链接、根目录换身、目标冲突；正在视频分析的版本不移动。
- 用户本轮纠正：撤掉回收整理弹窗，收藏页只保留垃圾桶图标加「本地删除」按钮，一次点击先整理已有删除快照，再请求打开固定回收目录。空记录或全部已整理也能打开；不加入自动永久删除。后端恢复与目录保护能力保留，界面不再提供复杂列表/逐条控制。44px控件、键盘焦点、窄屏可用。
- 前端操作期间防重复点击并冻结画布写操作；未保存、待恢复或正在保存的分组草稿、导入/删除在途时阻止整理。失败逐阶段反馈；未知整理结果只读核对，不自动重放，核对到最新revision后才允许后续写入。
- 本轮公开测试边界：真实浏览器按钮与隔离HTTP/文件系统，验证整理后开访达、空/重复点击、部分失败、断响应核对、访达失败、草稿保护及六宽度。技术实现由Codex负责，不要求用户确认内部结构。
- 用户追加纠正：成功打开访达后不显示常驻结果行，也不汇总历史文件移走/不完整的红字。仅本次整理失败、打开失败或未知结果保留错误提示；后端缺失检测及恢复保护不变，不以隐藏提示解释为文件完整。
