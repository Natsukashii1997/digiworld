## 核心复述

这个应用从“个人 AI 能力操作台”，变成**用户每天只需打开的那一个网站**。它分成两个区：

- **工作区**：管理 AI 能力，推进项目。
- **生活区**：承载计划、信息、学习和兴趣。

工作区里最重要的三块是**项目空间、协同、知识仓库**。目标是让 3 个主力 Agent 在同时推进的 1–3 个项目上，严谨又省力地接力，用户不再在各 Agent 之间传话。

## 本轮核查的事实

- **Obsidian Vault 结构**：用户授权只读扫描，只看文件夹、数量和修改时间，没有读正文，也没有读笔记标题。
  - 共 989 篇笔记，体积 2.1GB。
  - GET NOTES/订阅博主 679 篇（69%），GET NOTES/Notes 177 篇（18%），系统（治理、索引、维护、验收）87 篇（9%），知识编译 27 篇，个人上下文 6 篇；工作、决定、待整理、生活合计 5 篇。
  - 几乎全部笔记在近 30 天内导入或生成。根目录有 25 本电子书（PDF、EPUB）；音频以 Get笔记的 ogg、mp3 为主。
  - 判断：输入多、自己产出的少；目录按“来源”组织，而不是按“用途”组织。
- **Jev**：TypeSafe AI 于 2026-09-15 发布的决策模型。它不生成文本，只返回结构化判断：分类、打分、路由，并附概率和置信度。目前只能通过托管 API 使用，需要排队申请。来源：[OpenRouter](https://openrouter.ai/blog/insights/what-is-jev/)、[Arize](https://arize.com/blog/typesafe-jev-llm-judge/)。
- **AI HOT**：
  - `aihot.news/api/v1/*` 提供匿名只读 API，个人非商业使用免费；对外商业用途须取得书面授权。依据是本机 `aihot` Skill 的说明。
  - 该 Skill 的源码在 [khazix-skills/aihot](https://github.com/KKKKhazix/khazix-skills/tree/main/aihot)。
- **DeepSeek Harness**：本机路径 `~/deepseek-harness`，是 DeepSeek 开源的 agent harness（dsh），采用插件化架构，自带 Web UI（127.0.0.1:3080）。目前处于开发者预览阶段，会有不兼容的变更。
- **炉子**：来自用户截图，涉及 Agent 总览（11 个）、内容清单与“存入炉子”、云端版本、跨 Agent 迁移、会话级上下文接力。
