## 隔离预览与历史候选

下面的预览入口仅用于合成验证，不是日常常驻入口。

非技术预览：在Finder进入本目录，双击 `preview.command`。它打开一份合成便签和悬浮球，正式便签不参与。点球→写一条→停手约1秒看到“已保存”；收起再打开内容仍在。程序正常退出后，在预览终端按回车可用同一份隔离数据重开，输入q结束整轮预览。预览恢复文件留在该终端显示的project/work目录；结束后隔离服务清理自己的合成主库。

候选构建需要本机已有Node与Swift，未新增依赖。开发者在项目根目录运行：

```sh
node node_modules/vite/bin/vite.js build --outDir work/floating524/candidate-dist
bash desktop/floating-notes/build.sh "$PWD/work/floating524/native-basic"
```

两者只输出到work，不替换正式dist。原生恢复区由`--state-dir`指定；默认位于候选app旁，预览脚本明确使用独立目录。内容绑定服务来源与dataRootIdentity，只存未完成稿，保存并主库回读后清除；互斥锁防止同一恢复区双开。当前App为本地临时签名；正式安装与自启状态以上文及当前项目状态为准。
